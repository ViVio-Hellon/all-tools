# 統合ツール(日報・看板・カレンダー・点検表)

4つのツールを **1つの入口(1つの窓)に大きなタブで並べた**ものです。**中は分けたまま**動きます
(ツールごとに別の Python。1つが止まっても、ほかのタブはそのまま使えます)。

| 大きなタブ | ツール | 版 | 元のリポジトリ |
|---|---|---|---|
| 日報 | 日報管理ツール | 4.22.0 | vba-daily-report-python-migration |
| 看板 | 資材発注看板システム | 3.1.0 | vba-production-board-python-migration |
| カレンダー | ライン管理カレンダー | 4.0.0 | vba-calendar-python-migration |
| 点検表 | 点検表 選択・印刷 | 2.0.0 | vba-inspection-sheet-python-migration |
| **大設定** | タブ表示権限(どの端末にどのタブを出すか)・共有の DB の置き場所・配布設定 | ― | (このリポジトリ) |

どのタブを出すかは、**ログインID と PC名** で決めます(python-web-tools のアクセス権限と同じ考え方の、
別の表 `タブ表示権限`)。どのラインでも全タブを出すわけではありません。

## 使い方

| ファイル | 使うとき |
|---|---|
| **`統合ツール.exe`** | **ふだんはこれ(デスクトップ版)。** 専用の窓で開きます。**ポートを使いません**(プロキシ・セキュリティ製品・ポートの取り合いに左右されない) |
| `Start.vbs` | exe が使えないときの予備(ブラウザ版)。ブラウザに同じ大きなタブが出ます |
| `start.bat` | ブラウザ版が起動しないとき、原因を見る(コンソールに経過が出る)。`start.bat --check` は確認だけ |
| `stop.bat` | ブラウザ版を止める(デスクトップ版は窓の「終了」で閉じる) |

- 開いたタブのツールだけが動き始めます(最初のタブが出たあと、ほかのタブも順に裏で起こします)
- 右上の **「終了」** と窓の **×** は、全ツールに「終わってよいか」を訊き、途中の処理(書き戻し・
  印刷など)があれば **1つの確認** にまとめて訊きます。各ツールの画面の「終了」も同じです
- **F5 / Ctrl+R はいま出しているタブだけ** を読み直します(ほかのタブの打ちかけは消えません)。
  **Alt+1〜9** で大きなタブを切り替えます
- 1つのツールが止まったら、そのタブにだけ理由と「もう一度開く」が出ます
- 大きなタブには **各ツールの版**(`VER4.22.0` など。各ツールの `config\app.json`)が出ます。
  窓が狭いときは版を隠し、タブに指を置くと出ます
- 右上の **「説明書」** (または **F1**。ツールの画面の中で押しても同じ)で、**いま開いているタブの
  操作説明書** を窓の中に重ねて開きます(画面の写真と番号の札入り。**Esc** で閉じる)。
  大設定のタブでは統合ツール・大設定の説明書が出ます。説明書は一式の中の
  `portal\static\manual\`(HTML と写真)にあり、社外のサイトにはつなぎません

### ブラウザ版とデスクトップ版は同時に動きません(どちらを後から開いても止まります)

| 先に動いているもの | 後から開いたもの | 動き |
|---|---|---|
| ブラウザ版 | 統合ツール.exe | 「ブラウザ版が動いています」と出して閉じる |
| 統合ツール.exe | ブラウザ版(Start.vbs) | 「デスクトップ版が動いています」と出して止まり、窓を前に出す |
| 統合ツール.exe | 統合ツール.exe | 開かず、開いている窓を前に出す |
| 各ツールのブラウザ版(`tools\<ツール>\Start.vbs`) | 統合ツールのそのタブ | そのタブに理由と「もう一度開く」(ほかのタブは使える) |
| 統合ツールのそのタブ | 各ツールのブラウザ版 | 「統合ツールの窓で動いています」と出して止まる |

## 大設定(タブ表示権限)

表は **python-web-tools と同じ共有の DB**(既定
`\\nlmfangyshrd\各課共有\0130_日軽稲沢\梱包課\AIM\【■】_参照用ファイル\梱包資材マスタ.sqlite3`)に、
**アクセス権限とは別の表** `タブ表示権限` として置きます。

| 管理番号 | ログインID | PC名 | 表示タブ | 既定タブ | 有効 | 備考 |
|---|---|---|---|---|---|---|
| 1 | | LINE1-PC | 日報, 看板 | 日報 | 1 | 1ライン |
| 2 | | WH-PC | 看板 | | 1 | 倉庫 |
| 3 | yamada | | すべて | | 1 | 管理者 |

- **空欄は「問わない」。** 大文字小文字・全角半角は区別しません。ログインIDとPC名の両方がある行は、両方合うときだけ
- 当てはまる行の表示タブを **全部足します**。`有効` が 0 の行は飛ばします
- **ログインIDもPC名も空の行は効きません**(全員に効いてしまうため)
- 表示タブは `日報` `看板` `カレンダー` `点検表`(正式名・英字の名前でも可)を `,` `、` `・` 空白で区切ります。`すべて` は全部
- 既定タブ(開いたときに出すタブ)は、当てはまる行のうち **いちばん絞った行**(ID と PC の両方 → PC だけ → ID だけ)のもの
- 表がまだ無い・1行も無い・共有に届かず手元の写しも無い → **すべてのタブを出します**(ラインを止めない)
- 表に行があるのに、その端末の行が無い → **ツールのタブは出さず、大設定だけ** を出します。大設定に、その端末の
  ログインID・PC名 が写せる形で出ます
- 共有に届かない日は、**前回読めた手元の写し** で決めます
- タブが増えたときはその場で足し、外れたタブは次に開いたときに消えます(打ちかけを消さないため)

**書き換え** は大設定の画面で行います(管理者パスワードで鍵を開ける。既定はほかのツールと同じ。30分さわらなければ
鍵が掛かる)。表が無ければ「表を作る」、行は「+ 行を足す」「直す」「消す」。共有の DB へ直接書き、2人が同時に同じ行を
直したときは、後の人に「読み直してから」を出します。**最初の1行を足すと、登録の無い端末からツールのタブが消えます**
(足す前に確かめます)。使う端末をまとめて登録してから運用を始めてください。

**配布設定**: 大設定の「配布設定を書き出す」で、この端末の共有の DB の置き場所・管理者パスワードを一式の直下の
`配布設定\` に書き出せます。配った先は起動したときに、その端末に無い項目だけ読み込みます。

## 一式の中身

```
統合ツール\
├─ 統合ツール.exe          デスクトップ版(GitHub Actions が作る AllTools.exe。リポジトリには入れない)
├─ Start.vbs / start.bat / stop.bat   ブラウザ版(予備)
├─ bridge.py               入口のデスクトップ版の入口(標準入出力。待ち受けない)
├─ start_app.py            ブラウザ版の起動(127.0.0.1:8700〜)
├─ process_manager.py      ブラウザ版を止める(stop.bat)
├─ config\                 app.json(版・名前)・tools.json(載せるツール。並び = 大きなタブの並び)
├─ portal\                 入口: 大きなタブの画面・大設定・タブ表示権限・配布設定(Flask)
│   └─ static\manual\       操作説明書(index・portal・各ツールの HTML と img\ の画面写真)
├─ tools\                  4つのツール(それぞれ今までどおりの一式。単体のブラウザ版も動く)
│   ├─ nippou\ kanban\ calendar\ inspection\
├─ src-tauri\              デスクトップ版の外枠(Rust/Tauri)
├─ scripts\                make_dist(配布用フォルダ)・desktop_smoke(exe を起動して確かめる)・アイコン
├─ tests\                  入口・外枠との取り決め・起動ファイル・配布の試験
└─ docs\                   統合_事前確認.md・デスクトップ版.md
```

## しくみ(ポートを使わない)

```
統合ツール.exe(Rust/Tauri)── 1つの窓。上に大きなタブ、下に各ツールの画面(iframe)
 ├─ 宛先ごとに受ける(ネットワークを通らない。Windows は http://<名前>.localhost)
 │    portal://(大きなタブ・大設定)        → 入口の Python(bridge.py → portal\)
 │    nippou:// kanban:// calendar:// inspection:// → それぞれのツールの Python(tools\<ツール>\bridge.py)
 ├─ 部品(CSS・JS・画像)は exe が自分で返す。それ以外は、そのツールの Python の標準入力へ
 └─ ツールの画面の頼みごと(別窓・保存・フォルダの選択・立て直し)は、
    ツールの画面 → 大きなタブの画面(送り元を確かめる)→ exe の順に渡る
```

| 言語 | 受け持ち |
|---|---|
| Rust(`src-tauri\`) | 窓・各ツールの Python の起動と監視・宛先ごとの振り分け・部品を返す・台本の差し込み・別窓・保存/選択のダイアログ・同時起動の防止・まとめた終了の確認 |
| Python(`portal\`・`tools\`) | 入口(タブ表示権限・大設定)と各ツールの業務(今までどおり) |
| VBScript | Access(日報)・Excel(点検表)の操作(今までどおり) |
| JS | 画面(今までどおり)。大きなタブの画面は `portal\static\js\shell.js` |

詳しくは [docs/デスクトップ版.md](docs/デスクトップ版.md)、移行前に機能を1つずつ確かめた結果は
[docs/統合_事前確認.md](docs/統合_事前確認.md)。

## 要るもの

- Windows 10/11、**Python 3.9 以上**と `pip install -r requirements.txt`(Flask と waitress の 2 つだけ。4ツールとも同じ)
- デスクトップ版は **WebView2 ランタイム**(Windows 11 には入っている。Windows 10 も Edge の更新で入っていることが多い)
- Access(ACE)・Excel は、今までどおり日報・点検表が使います

## 配る

1. GitHub Actions の「デスクトップ版(Windows)」の成果物 **AllTools-windows** の `AllTools.exe` を、一式のフォルダの直下に置く
2. (必要なら)大設定・各ツールの設定画面で配布設定を書き出す
3. `scripts\make_dist.bat` → 一式の隣に `統合ツール_VER1.0.0\` ができる(`統合ツール.exe` の名前で exe が入る。
   tests・src-tauri・端末ごとの設定は入らない)。中の `配布メモ.txt` に、入れたものと配った先ですることがあります

## 開発

```
python -m unittest discover -s tests -t .                       # 入口(95 件)
cd tools\nippou     && python -m unittest discover -s tests       # 日報(3,789 件)
cd tools\kanban     && python -m unittest discover -s tests       # 看板(866 件)
cd tools\calendar   && python -m unittest discover -s tests -t .  # カレンダー(720 件)
cd tools\inspection && python -m unittest discover -s tests -t .  # 点検表(245 件)
cd src-tauri && cargo test && cargo build --release              # 外枠(22 件)・exe
python scripts\desktop_smoke.py --exe src-tauri\target\release\AllTools.exe   # exe を起動して確かめる
```

GitHub Actions(`.github/workflows/desktop-windows.yml`)が Windows の上で、上の全部と exe の起動確認を流します。

**ツールの版を上げたら、説明書(`portal\static\manual\<ツール>.html`)の `VER…` と中身も見直します。**
版が食い違うと入口の試験(`tests\test_manuals.py`)が落ちます。この試験は、説明書が全部あって互いに
辿れること・社外のサイトのものを使っていないこと・写真が手元にあって重すぎないことも見ます。
