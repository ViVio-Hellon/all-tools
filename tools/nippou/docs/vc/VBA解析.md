## 1. このシステムは何をしているのか

**紙管に巻かれた VC フィルム(ビニール)の残り長さを、巻きの厚み(肉厚)から
計算し、あと何枚ぶんの製品に貼れるかを出す計算機**です。

```
品種を選ぶ ─▶ VC厚・内径が入る ─▶ 肉厚を測って入れる ─▶ [計算]
                                                     │
          ┌──────────────────────────────────────────┘
          ▼
   VC長さ(m) = 巻き断面の面積 ÷ フィルム厚
   枚数      = VC長さ ÷ 製品の丈(2010 / 2510 / 3065 mm と、任意の経寸丈)
```

- **肉厚** … 紙管の外周からロール外周までの厚み(mm)。現場で測る値
- **VC厚** … フィルム1枚の厚さ(mm)。品種ごとに決まっている
- **内径** … 「内径(紙管の外径)」とコメントにある。フィルムを巻いている紙管の外径(mm)
- **VC長さ** … 巻いてあるフィルムの長さ(m)
- **枚数** … VC長さで何枚の製品に貼れるか(小数1桁)

データの保存・読み込み・印刷は**しません**。すべて画面の中で完結する計算です。

### 2.1 ブック `VC計算.xlsx`(計算の正)

利用者の判断で、**正はこのブックのセルの式**です。シートは2枚で、品種ごとに
VC厚・内径を入れた枠が並び、長さ(または肉厚)を入れると式が答えを出します。

| シート | 式(R1C1 を A1 に直したもの) | VBA との比較 |
|---|---|---|
| 自動計算 肉厚から長さ | `=PI()*((C7*2+C9)*(C7*2+C9)-C7-C9*C9)/(4*C8)/1000`<br>C7 肉厚 / C8 ビニール厚 / C9 内径 | `VC長さ` と**同じ**(`- 肉厚` の項も同じ) |

TF200 0.06 / 87、V325 0.13 / 83、B500 0.06 / 94、VE 0.1 / 98)。
**VBA はブックの式を正しく写しています。** ブックの結果セルは書式が「標準」で、
小数を丸めずに出します。R575B はブックにもありません。

## 6. 計算式

### 6.1 VC長さ(`VC長さ`)

```vb
pi = 4 * Atn(1)
y = Format(val(.COatu), "0.00")   ' 肉厚
a = Format(val(.VCatu), "0.00")   ' VC厚
b = Format(val(.Inside), "0.00")  ' 内径
x = pi * ((y * 2 + b) * (y * 2 + b) - y - b * b) / (4 * a) / 1000
If .VClen = "" And .COatu <> "" And .VCatu <> "" And .Inside <> "" Then
    .VClen = Format(x, "0.0")
End If
```

$$
\text{VC長さ[m]} = \frac{\pi\{(2y+b)^2 - y - b^2\}}{4a} \div 1000
$$

巻きの断面(外径 `2y+b` の円 − 内径 `b` の円)をフィルム厚 `a` で割った長さ。
**式の中に `- y` が1つ余計に入っています**(幾何の式は `(2y+b)² − b²`)。
コメントに残る Excel の式 `=PI()*((C5*2+C7)*(C5*2+C7)-C5-C7*C7)/(4*C6)/1000`
も同じ形なので、Excel 版から写したものです。その上にコメントアウトされた
旧式 `x = PI * y * (y + b) / a / 1000` は `- y` の無い正しい幾何の式です。

影響は小さく(VC厚 0.10 のとき、肉厚 5mm で約 0.04m、47mm で約 0.37m 短く出る)。

**VER1.2.0 で正しい式に直しました**(利用者の判断)。`- y` は面積(mm²)から長さ(mm)を
引く意味の無い項で、同じ VBA の旧式・逆算式・幾何の式(巻き数 y÷a × 平均の1周
π×(b+y))のどれにも無く、あったりなかったりするのは転記ミスと判断しました。

$$
\text{VC長さ[m]} = \frac{\pi\{(2y+b)^2 - b^2\}}{4a} \div 1000 = \frac{\pi\, y\,(y+b)}{a} \div 1000
$$

これで順算と逆算(§6.2)が同じ式になり、肉厚 → 長さ → 肉厚 が元に戻ります。
**ブック「自動計算 肉厚から長さ」の `-C7` も同じく取り除いてください**(正を揃えるため)。

### 6.2 肉厚の逆算(`肉厚`)

```vb
y = Format(val(.VClen), "0.00")   ' VC長さ
x = (-b + Sqr(Abs(b ^ 2 + (4 * a * y * 1000 / pi)))) / 2
If .COatu = "" And .VCatu <> "" And .Inside <> "" And .VClen <> "" Then
    .COatu = Format(x, "0.0")
End If
```

正しい式(`- y` 無し)を肉厚について解いた形で、ブック「自動計算 長さから肉厚」と
同じです。VER1.2.0 で順算も正しい式に揃えたので、順算と逆算が一致します。§8 のとおり VBA の画面からは到達できませんでしたが、
利用者の判断で **Web 版では使えるようにしました**(Q3 解決)。

### 6.3 枚数(`VC枚数`)

```vb
x = Format(val(.VClen), "0.00")
.M1 = Format((x * 1000 / 2010#), "0.0")
.M4 = Format((x * 1000 / 2510#), "0.0")
.M5 = Format((x * 1000 / 3065#), "0.0")
If .Prolen <> "" And IsNumeric(.Prolen) = True Then
    .MK = Format((x * 1000 / val(.Prolen)), "0.0")
End If
```

**VC長さは画面に出た `0.0` の値で割ります**(計算途中の全桁ではない)。
Web 版も、画面に出す VC長さ(小数1桁)から枚数を出します。

### 6.4 丸め

| 場面 | 書式 | 丸め方 |
|---|---|---|
| 計算に使う入力値 | `Format(val(x), "0.00")` | 小数2桁 |
| 欄を抜けたとき | `0.0` / `0.00` | 同上 |
| 結果の表示 | `Format(x, "0.0")` | 小数1桁 |

VBA の `Format` は**四捨五入(0.5 は 0 から遠い側)**で、`Round`(銀行丸め)とは
違います。倍精度の値は有効15桁の10進に直してから丸めます(`Format(12.35,"0.0")` は
`12.4`)。Web 版は `app/services/vba_compat.py` で同じ丸め方をします。

## 7. 判定ロジック(業務ルール)

1. **計算の前提** … 肉厚・VC厚・内径の**3つとも**入っていなければ何もしない
   (メッセージも出さない)
2. **VC長さは空のときだけ計算する** … 欄に値が残っていれば上書きしない
3. **肉厚は空のときだけ逆算する** … ただし 1 により肉厚は必ず入っている
4. **枚数は VC長さが数値のときだけ** … 定尺3種は常に、経寸丈は数値のときだけ
5. **品種を選ぶと** … VC厚・内径・業者名が入り、肉厚と VC長さが空になる
6. **ニットウ2品種は内径を大(95.0)/小(87.0)から選ぶ** … 選ぶまで内径は空
7. **それ以外の品種は内径が決まっている**
8. **数値でない入力は打った瞬間に消える**(肉厚・VC厚・内径・VC長さ)

Web 版では 1 を「肉厚が空でも VC長さがあれば計算する(逆算)」に広げています(Q3)。


## 10. エラー処理

`On Error` は1つもありません。次の入力で**実行時エラー(VBA のデバッグ画面)**
になります。

| 入力 | 起きること |
|---|---|
| VC厚 = 0(または 0.004 以下 → `0.00` に丸まる) | 0 除算(エラー 11)。VC長さの計算は `If` の**前**にあるので、VC長さが入っていても落ちる |
| 経寸丈 = 0 | 0 除算。M1/M4/M5 は書いたあとで落ちる |

入力欄の検査は「数値でなければ消す」だけです。`-` や `.` から打ち始めると
その場で消えるので、負の数は実質打てません(貼り付けなら入る)。
経寸丈には検査がなく、数値でなければ MK を**更新しない**(前の値が残る)。

## 14. VBA との差分(意図して変えたところ)

**計算式・丸め・判定の順序は1つも変えていません。** 変えたのは、Web で
そのまま再現すると**誤った数値を出したまま気づけない**ところだけです。

| # | VBA | Web 版 | 理由 |
|---|---|---|---|
| D1 | 計算後に肉厚を変えて再計算しても、VC長さが残っていると**古い VC長さのまま**(ルール2) | 肉厚・VC厚・内径を直した時点で、**計算で入った** VC長さと枚数を消す。**手で入れた** VC長さは残す(ルール2どおり) | 新しい肉厚の横に古い長さが並ぶと、誤りに気づけない |
| D2 | 品種を変えても枚数(M1/M4/M5/MK)は前の値が残る | 品種を変えたら枚数も消す | 同上 |
| D3 | 数値でない文字は打った瞬間に消える | 消さずに、欄の下に理由を出して計算しない | 打った内容が黙って消えると、何が起きたか分からない |
| D4 | VC厚 0・経寸丈 0 で実行時エラー | 理由を出して計算しない(経寸丈 0 のときは MK だけ出さない) | 画面が止まらないようにする |
| D5 | 経寸丈が数値でないとき MK は前の値のまま | MK を空にして理由を出す | D1 と同じ |
| D6 | 全角数字・`1,000`・`&H10` なども `IsNumeric` が通す | 全角は半角に直して受ける。カンマ・16進などは断る | `1,000` を経寸丈に入れると VBA は `Val` で 1 と読み、MK が 1000 倍になる |
| D7 | 負の数は打てない(貼り付けなら入る) | 負の数は断る | 実質同じ |
| D8 | 肉厚の逆算は画面から使えない | 肉厚が空で VC長さがあれば逆算する | 利用者の判断(Q3)。ブック「長さから肉厚」と同じ |
| D9 | 早見表は紙の数値(手で整数にしたもの) | 正しい式から出す(切り捨て)。13セルが紙と1m違う | 利用者の判断(Q6)。§12 |
| D10 | VC長さの式に `- y`(転記ミス)。逆算とは式が違う | `- y` を取り除いた正しい式。逆算と一致 | 利用者の判断(Q5)。§6.1。長さは 0.04〜0.42m 長く出る |

表示だけの違い: VE系の VC厚は VBA では `0.1`(整形されない)、Web 版は `0.10`。
計算に使う値は同じです。
