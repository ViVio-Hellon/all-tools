基本寸法計算

大円柱半径 = (肉厚 × 2 + 内径) / 2 = (400 × 2 + 557) / 2 = 678.5 mm
小円柱半径 = 内径 / 2 = 557 / 2 = 278.5 mm

体積計算

大円柱体積 = π × 大円柱半径² × コイル幅 = π × 678.5² × 1250 = 1,809,647,835 mm³
小円柱体積 = π × 小円柱半径² × コイル幅 = π × 278.5² × 1250 = 303,596,529 mm³
コイル体積 = 大円柱体積 - 小円柱体積 = 1,809,647,835 - 303,596,529 = 1,506,051,306 mm³
コイル体積(cm³) = コイル体積(mm³) / 1000 = 1,506,051,306 / 1000 = 1,506,051.3 cm³

重量計算

重量(g) = 体積(cm³) × 比重(g/cm³) = 1,506,051.3 × 2.70 = 4,066,338.5 g
重量(kg) = 重量(g) / 1000 = 4,066,338.5 / 1000 = 4,066.3 kg

長さ計算

断面積 = π × (大円柱半径² - 小円柱半径²) = π × (678.5² - 278.5²) = 1,204,841.0 mm²
面積 = コイル体積(mm³) / 板厚(mm) = 1,506,051,306 / 1.00 = 1,506,051,306 mm²
長さ(mm) = 面積(mm²) / コイル幅(mm) = 1,506,051,306 / 1250 = 1,204,841 mm
長さ(m) = 長さ(mm) / 1000 = 1,204,841 / 1000 = 1,204.8 m

巻き数計算

巻き数 = 肉厚(mm) / 板厚(mm) = 400 / 1.00 = 400.0 ≈ 400 巻
