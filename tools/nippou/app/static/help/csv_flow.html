日報のCSV ── 打った行がどう展開されるか

日報管理ツールが書き出す集計CSVの作り方です。打つ場所は1つ(日報入力)だけで、保存のたびに「集計」の表へ並べ直し、その表からCSVを3本作ります。VBA の「印刷フォーマット → 集計フォーマット(Agg_OutPut / Aggre_Calcul)」と同じ二段構えです。

1全体の流れ

出どころ: services/summary.py(②を作る)・logic/packing_agg.py(行と停止の並べ直し)・reporting/csv_export.py(③を書く)

21行がどう分かれて、どう戻るか

例: ページ1の3行目に、LOT H5422S0 で停止を2つ(① 3 20分、② ﾌｫｰｸ 15分)打った場合。

33本それぞれの中身

集計_ 直ごとの合計 14列

  • 1行 = 1直(その日・そのラインの直ぜんぶ)
  • 合計枚数 = 実績枚数の和、合計重量(t) = 実績重量 ÷ 1000
  • 停止は3分類の分と、その合計
  • 稼働時間 = 1440 − 停止合計
  • 操業時間 = 1440 − 管理ロスだけ
  • 稼働率(%) = 稼働時間 ÷ 1440 × 100
  • 生産性(t/h) = 重量(t) ÷ 稼働時間(h)

集計明細_ 打った行を全部

  • 並びは 日付 → 直 → ページ → 行(紙をめくる順)
  • 列は紙の左から右 + 紙の外の6欄 + 作業者など + 引当番号
  • 作業停止④⑤はいちばん後ろ(前からある列の位置を動かさない)
  • 空の行(何も打っていない行)は出さない

停止内訳_ 手を打つための表

  • 直を混ぜない(3直だけ長い、が見える)
  • 並びは 直 → 分類(マスタの順) → 時間の長い順
  • 「区分」列で 直の合計 / 1件ずつ を絞り込める
  • 割合はまとめの行にだけ入れる

4打った字と CSV の字の違い(明細)

CSV は②の「値」から作るので、打った文字そのものではありません。打った字そのものが要るときは紙(印刷)を見ます。

打ったもの集計(値)CSV に出る字理由
空欄の数の欄0空欄12行×30列が 0 で埋まらないように。打っていない所は空いているのが正
10001000.01000割り切れれば小数点を出さない
57.5(作業時間など)57.557.5小数はそのまま(丸めない)
時・分 088082桁に詰め直す。0時0分は 00(0 は本当の値)
停止の記号だけ・分は空0分・1回記号 / 空欄書いたのに回数に出ない、を避ける
停止の分だけ・記号は空作らない出ないどの分類にも入れようがない(VBA も外していた)

5いつ書き出すか

きっかけ出す先中身
日報の保存(確定・自動保存・新しいページ)1つ目 集計CSVの出力パスその日・そのラインの3本を書き直す。書けなくても保存は成功のまま(画面で知らせる)
「共有へ保存」で送れたとき2つ目 決めてあれば送った日の3本。同じ日にまだ送っていない直が残っていれば、送れるまで待つ(共有に無い中身を先に届けない)
集計・グラフの「期間を書き出す」1つ目(と2つ目)期間のうち中身のある日だけ
過去日報・CSV の取り込み1つ目(と2つ目)取り込んだ日の3本
月の初めて(または消された)とき年月のフォルダCSVの読み方.txt(列の説明)と 計算内容.csv(式)を1つだけ置く

集計管理の「4本ともCSVに出す」は、これとは別の書き出しです ── 画面に出ている表(日別・直別・ロット別・ロット一覧)を そのまま 集計_日別_開始日_終了日_ライン.csv などに出します。出どころは同じ②の集計なので、数は合います。

停止の分類は記号の文字種で決まります: 数字 → 管理ロス設備停止 / カタカナ → 段取り・突発停止 / 英字 → ハンドリング停止 / それ以外 → その他(VBA の CheckCharType と同じ)。
