    考え方と計算

    標準作業時間と梱包力が、何を・どう数えているか
    1. 標準作業時間とは 2. 標準の出し方 3. 梱包力とは 4. 計算の例 5. 根拠 6. 気をつけること 7. オペレーター構成

    1. 標準作業時間とは

    その作業を、決められた条件で、ふつうのペースで行ったら何分かかるか、です。

    「決められた条件」は、ライン・用途コード・包装仕様NO・サイズ(厚×幅×丈)が同じこと。 班ごとの標準と、班をまたいだライン全体の標準(全班)の両方を作ります。

    2. 標準の出し方

    1. 1作業ごとに「人分」にする ── 人数が多いと時間は短くなるので、時間と人数を掛けて 「何人で何分ぶんの仕事だったか」にしてから、梱包数で割ります。 
      1梱包あたりの人分 = 作業時間 × 作業人数 ÷ 梱包数
      梱包数の無い作業は、枚数で同じように割ります(1枚あたりの人分)。
    2. 同じ条件の作業を集めて、真ん中の値(中央値)を標準にします。 件数が{{ guide.min_samples }}件より少ない条件は「仮」の印が付きます。 
      標準(人分/梱包) = 同じ条件の「1梱包あたりの人分」の中央値
    3. 使うときは元に戻す ── 梱包数と人数を入れると、標準なら何分かが出ます。 
      標準作業時間(分) = 標準(人分/梱包) × 梱包数 ÷ 作業人数
標準との差(分)   = 実際の作業時間 − 標準作業時間    (+ は標準より長くかかった)

    作業時間は日報の「作業時間」(開始〜終了から停止時間を引いたもの)です。 次の作業は標準に数えません(実績には理由つきで残ります): {% for reason in guide.excluded %}{{ reason }}{% endfor %}

    3. 梱包力とは

    ゲームの DPS(1秒あたりに与えるダメージ)の梱包版です。 ただしダメージのかわりに標準作業時間で数えます。

    梱包力 = 標準人分の合計 ÷ 実人分の合計 × {{ guide.base }}
  標準人分 = 全班の標準(人分/梱包) × 梱包数     … 標準のペースなら何人分かかる仕事か
  実人分   = 作業時間 × 作業人数               … 実際に何人分かかったか
    梱包力意味
    120標準の1.2倍の速さ(標準なら72分かかる仕事を60分で)
    {{ guide.base }}標準どおり(全班の中央値と同じペース)
    80標準の0.8倍(標準なら48分の仕事に60分かかった)

    なぜ「1時間に何梱包」ではないのか。 大きい板・手間のかかる包装をやった人ほど、 梱包数は少なくなります。同じ1時間を同じペースで働いても:

    {% for d in guide.difficulty %} {% endfor %}
    やった仕事(2人で60分)標準(人分/梱包) 梱包数1人1時間あたり梱包数 標準人分梱包力
    {{ d.label }}{{ d.standard }} {{ d.packages }}{{ d.per_hour }} {{ d.standard_pm }}{{ d.power }}

    梱包数で比べると倍ちがいますが、梱包力はどちらも{{ guide.base }}です。 難しい仕事は標準人分が大きい(=大きいダメージ)ので、やった仕事の重さで比べられます。

    • 比べる標準はいつも全班のもの。 班の標準と比べると、どの班も自分のふつうと比べて {{ guide.base }}前後になり、班どうしを比べられません。
    • 標準がまだ無い・「仮」の条件の作業は比べません。 1件だけの標準はその作業そのものなので、 比べると必ず{{ guide.base }}になります。外したぶんは「比べた作業 ◯/◯件」に出ます。
    • 作業者ごとは、その直に居た全員に同じ数を入れます。 作業者欄は直ごとに全員の名前で、 行ごとに誰がやったかは分からないためです(全体には1回だけ数えます)。
    • 1件ずつの梱包力の平均ではなく、合計どうしで割ります。 小さいロット1件の極端な値に 引っ張られないように、仕事の量で重みが付きます。

    5. 根拠 ── 生産管理(IE)の考え方との対応

    考え方そのものは、工場の生産管理(IE: インダストリアル・エンジニアリング)で昔から使われている ものと同じ形です。標準の決め方は、それの簡易版です。

    このツール生産管理(IE)でいうと同じところ・違うところ
    標準作業時間 標準時間(JIS Z 8141「生産管理用語」)── 慣れた人が、決められた条件で、 ふつうのペースで仕事をするのに要る時間 考え方は同じ
    標準を過去の実績から出す 実績資料法 ── 標準時間の決め方の1つ。ほかにストップウォッチで測る方法(時間研究)、 動作から組み立てる方法(PTS法)などがある IE の正式な標準時間は、測った時間を「ふつうのペース」に直し(レイティング)、 余裕(疲れ・用足しなど)を足して作る。このツールはどちらもせず、実績の中央値をそのまま使う
    中央値 統計の代表値のうち、外れ値に強いもの トラブルで長引いた日に標準が引っ張られない(4. の例)
    梱包力 作業能率 = 標準時間で数えた出来高 ÷ 実際にかかった時間 × 100。 設備総合効率(OEE)の性能稼働率(基準サイクルタイム × 加工数 ÷ 稼働時間)も同じ形 式の形は同じ。名前と「ゲームの DPS」のたとえはこのツールのもの
    合計どうしで割る 期間の能率は「標準時間の合計 ÷ 実際の時間の合計」で出すのがふつう 同じ

    このツールで決めたこと(決まった根拠は無く、使いながら見直すもの):

    • 件数{{ guide.min_samples }}件未満を「仮」にする(少なすぎると中央値が当てにならない、の目安)
    • 人分 = 作業時間 × 作業人数(仕事の量は人数に比例する、と置いている)
    • 作業者ごとは、直に居た全員に同じ数を入れる

    6. 気をつけること

    • 標準は「この現場のこれまでのふつう」で、「あるべき速さ」ではありません。自分たちの実績の 真ん中と比べるので、全体の梱包力は{{ guide.base }}前後に来やすい作りです。
    • 人数を倍にしても、時間がちょうど半分になるとは限りません。 人数の違う作業どうしは、 少し割り引いて見てください。
    • 停止は入っていません。 作業時間は停止を引いたあとなので、梱包力は「動いているときの速さ」です。 止まりが多いかどうかは、停止の集計で見てください。
    • ロットごとの段取りも、梱包数に比例として数えています。 少ない梱包数のロットは、 段取りのぶん遅く見えることがあります。
    • 作業者ごとの数は、その人が居た直の速さです。個人の腕前そのものではありません。
    • 件数が少ない条件(「仮」)は比べないので、珍しい仕事が多い期間は「比べた作業」が少なくなります。

    7. オペレーター構成

    班員名簿の「オペレーター」で、作業をした顔ぶれを分けます。 {% for kind, meaning in guide.operator_kinds %}{{ kind }} {{ meaning }}{% endfor %}

    オペレーター構成 = 作業者欄の名前を、名簿の区分で数えたもの
例: 作業者「{{ guide.operator_example.workers }}」 → {{ guide.operator_example.label }}
    • 標準の面のまとめ方「オペレーター構成ごと」で、条件 × 構成の標準が出ます(班で絞ると、その班の作業だけで)。
    • 同条件の作業には、1件ずつ「オペレーター構成」の列が付きます。
    • 梱包力のまとめ方「オペレーター構成」で、構成ごとの速さを比べます(比べる標準は、いつもの全班のもの)。 作業者ごとには、その人の区分が名前の右に出ます。
    • いまの名簿で数えます。 名簿を直すと、過去の作業の構成も変わります。
    • {{ guide.operator_kinds | map("first") | join(" / ") }} 以外の値・空・名簿に無い名前は 「{{ guide.no_kind }}」です。読めない値は画面の上とマスタ管理の班員名簿に出ます。
