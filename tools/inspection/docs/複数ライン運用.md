# 複数ラインでの運用

複数のラインで同時に使ったときに、互いに壊し合わないかを見直した結果です(VER1.3.0)。
試験は `tests/test_multi_line.py`。

## 想定している使い方

| 形 | 例 |
|---|---|
| アプリ本体を共有フォルダに1つ置き、各ラインのPCから起動する | `\\サーバ\…\点検表アプリ\Start.vbs` |
| アプリ本体を各PCへコピーして使う | `C:\点検表アプリ\Start.vbs` |
| 点検表は共有フォルダに1か所。複数のPCが同時にプレビュー・印刷する | `\\nlmsrvngy03\…\一括管理_点検表` |
| 1台のPCで複数のラインを受け持つ | 既定のプリンターを切り替える・画面を2つ開く |

## 何を共有し、何を分けているか

| もの | 置き場所 | 複数ラインで |
|---|---|---|
| アプリ本体(.py / .vbs / 設定) | 共有フォルダでもよい | **読むだけ**。どのPCも書かない(下の1)。例外は、管理者が「配布設定を書き出す」を押したときの `配布設定\` だけ |
| 配布設定(`配布設定\設定.json`) | アプリのフォルダの直下 | 各PCが起動時に読む。**その端末ですでに設定してある項目は上書きしない** |
| 点検表(Excel) | 共有フォルダ | **読み取り専用・通知なし**(`ReadOnly:=True, Notify:=False`)で開き、保存せずに閉じる。ほかのPCが同時に開いていても、編集中の人がいても、ロックを取らない |
| ロック・ログ・一覧の控え・プレビュー画像・利用者設定 | 各PC・各利用者の `%LOCALAPPDATA%\InspectionSheetPrint` | PCごと・利用者ごとに別。混ざらない |
| 待ち受けのポート | 各PCの 127.0.0.1(8733〜8736) | PCの中だけ。ほかのPCとはぶつからない |
| Excel | 各PCで、このアプリが起動した非表示の Excel | 利用者が自分で開いている Excel とは別。そちらには触れない |
| プリンター | 各PCの既定のプリンター | 印刷の確認と進み具合の画面に出る |

## 見直して直したこと(VER1.3.0)

| # | 起きうること | 手当て |
|---|---|---|
| 1 | 本体を共有フォルダに置くと、各PCが Python のキャッシュ(`__pycache__`)を本体のフォルダへ書いていた | 起動・停止のどちらも本体のフォルダへ書かない。キャッシュは各PCのローカル領域へ |
| 2 | 1台で複数ラインを受け持ち、既定のプリンターを切り替えると、使い回している Excel が**前のラインのプリンターへ印刷**する(Excel は起動したときのプリンターを使う) | 既定のプリンターが替わっていたら Excel を起動し直してから印刷する |
| 3 | プレビューの途中で、同じPCの別の作業が Ctrl+C をすると、**コピーされたものを点検表のプレビューとして出す**おそれ | クリップボードの持ち主がこのアプリの Excel かを確かめ、違えばコピーし直す(2回まで)。それでも駄目なら「もう一度プレビューしてください」と出す |
| 4 | 共有フォルダのアプリを動作中に新しい版へ入れ替えると、古い Python と新しい処理プログラム(VBScript)が組み合わさる | 組み合わさる前に止め、「起動し直してください」と出す。画面の上にも「新しい版が置かれました」の帯を出す |
| 5 | Excel の後片付けが、**まだ動いているほかのアプリの Excel** を止めうる(記録の持ち主を見ていなかった) | 記録に持ち主(PID + 生成時刻)を残し、持ち主が動いているものには触れない |
| 6 | 1台のPCで画面を2つ開いたとき、片方の印刷中にもう片方が印刷すると、**相手の印刷の進み具合が自分のもののように出た** | 「ほかの画面で印刷中です(n/m 件目)」と断り、進み具合の題に「(ほかの画面から開始)」と出す |
| 7 | 本体を入れ替えたあと、帯(接続断・新しい版)が出ると画面の下(印刷ボタン)が押し出された | 帯のぶん本体が縮む |

2 と 3 は Windows の実機(Excel・プリンター・クリップボード)で確かめる必要があります
(この試験は Excel の代わりの偽物で流れだけを確かめています)。

VER1.2.0 で直したもの(stop.bat とアプリの終了処理が同時に Excel の記録を書き換えると
失敗することがあった)も、複数のプロセスが同じものを触る問題の1つです。

## タブを何枚も開いたときの送受信(VER1.4.1)

ツールのタブを3枚(A・B・D)と、ほかのサイトのタブ(C)を同じブラウザで開いて試しました
(Playwright で実際のブラウザを動かす。Excel は模擬)。

| 試したこと | 結果 |
|---|---|
| 3枚の画面番号と、各要求が名乗る番号 | 3枚とも別。どの要求も自分の番号を付けていた |
| 3枚から同時にプレビュー(別々の点検表) | 3枚とも自分の点検表の画像を受け取った。Excel は1件ずつ順番に作る |
| 3枚から同時に印刷 | 1枚だけ受け付け、2枚は「ほかの画面で印刷中です」。その2枚の進み具合の題は「(ほかの画面から開始)」 |
| 印刷中に3枚が進み具合と接続確認を取りに行く(90回) | すべて応答。平均 0.02秒・最大 0.12秒 |
| 印刷中にほかのタブがプレビュー | 印刷が終わってから出る |
| 別のタブから印刷を中止 | 始めたタブにも「印刷を中止しました」が届く |
| ほかのサイトのタブ(C)から読む・終了させる・心拍を偽る・枠に入れる | すべて断られた(403「別オリジンからの要求を拒否」)。アプリは動き続けた |
| 設定を2枚で開き、Aでパスワードを変える | Bの表示は古いままだが、Bが古いパスワードで操作すると断られる(正はサーバ) |
| 2枚を閉じて1枚残す | 動き続ける |
| 1枚を開いたまま再起動 | 同じ番号で立ち上がり、開いたままのタブが自分でつながり直した |
| 最後の1枚を閉じる | 約9秒で終了(閉じる合図のあと8秒待つ) |

見つけて直したもの:

| # | 起きうること | 手当て |
|---|---|---|
| 8 | プレビューで↓を押し続けると、途中の点検表まで全部 Excel に作らせ、最後のものが出るまで待たされた。順番待ちの要求がサーバの手(8つ)をふさぎ、**ほかのタブの進み具合・接続確認まで止まった** | 同じ画面から次の要求が来たら前の要求は順番待ちをやめる。↓↑は止まってから頼む。順番待ちは4件まで |
| 9 | 再起動した直後に前と違う番号(ポート)で立ち上がり、開いたままのタブがつながり直せなかった | 空きの確かめ方をサーバの待ち受けと同じ条件にし、同じ番号で立ち上がる |
| 10 | 動いているあいだにプレビューの控えのフォルダが消されると、プレビューが出なくなった | 作り直して続ける |

## 運用の決まり

### 新しい版を配るとき(本体を共有フォルダに置いている場合)

1. 共有フォルダの本体を新しい版に入れ替える(フォルダごとコピー)
2. 動いているラインの画面には、15秒ほどで「新しい版が置かれました」の帯が出る
3. 各ラインは**印刷が終わった区切りのよいところで「終了」**し、Start.vbs で起動し直す
   - 起動し直さなくても、古い版のまま動き続ける(壊れはしない)
   - Excel の処理を始めようとした時点で入れ替わりに気づくと、「起動し直してください」と出して止まる
   - 次に Start.vbs を押せば、古い版は自動で終わり、新しい版が立ち上がる

### 設定を全ラインに揃えるとき(配布設定・VER1.4.0)

1. どれか1台で「設定」→「点検表フォルダ」を決め、必要なら「管理者パスワード」を変える
2. 「設定」→「配布設定」で入れる項目を選び、管理者パスワードを入れて「配布設定を書き出す」
3. アプリを共有フォルダに置いていれば、それで全ラインに届く(各PCへコピーしているなら、
   `配布設定` フォルダもコピーする)
4. 各ラインは**次に起動したとき**に読み込む。ただし、その端末ですでに設定してある項目は
   そのまま(ライン専用のフォルダを使っている端末を上書きしない)
5. 揃えたい端末では「設定」→「配布設定」→「配布設定を読み込み直す」(管理者パスワード)

ライン別に別の点検表フォルダを使う場合は、配布設定に点検表フォルダを入れずに書き出すか、
各ラインの「点検表フォルダ」で個別に指定します(個別の指定は配布設定で上書きされません)。

### 1台で複数ラインを受け持つとき

- 印刷先は **Windows の既定のプリンター**。ラインを替えたら既定のプリンターを替える
  (印刷の確認に出るプリンター名を見てから「印刷する」を押す)
- 画面(タブ)は何枚開いてもよいが、印刷は同時に1つだけ。先の印刷が終わるまで待つ
- ほかの画面で始めた印刷も、どの画面からでも中止できる(同じPCの同じ利用者なので)

### 気をつけること

- プレビューを作る瞬間は、このアプリの Excel がクリップボードを使う。そのとき利用者が
  コピーしていたものは上書きされる(VBA 版と同じ)
- 1台の Windows に複数の人が同時にログインして使う(リモートデスクトップの共有端末など)と、
  使えるポートは 8733〜8736 の4つ。5人目は起動できない(`config/app.json` の `port_retry` で増やせる)
- ライン別に別の点検表フォルダを使う場合は、各PC(各利用者)の「設定」→「点検表フォルダ」で
  指定する。設定は利用者ごとに保存され、ほかのPCには影響しない(配布設定でも上書きされない)
