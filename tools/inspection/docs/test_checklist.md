# テスト項目(要件定義書 39・40)

- **自動**: `python -m unittest discover -s tests -t .`(Windows 以外でも実行可。Windows でも GitHub Actions で流す)
- **画面**: 模擬モード(`start.bat --demo`)+ ブラウザ(Playwright / Chromium)で確認済み
- **実機**: Windows・Excel・プリンターのあるラインPCで確認が必要

## 起動

| 確認項目 | 方法 | 区分 |
|---|---|---|
| 通常起動できる | Start.vbs をダブルクリック | 実機 |
| 起動待機画面がすぐ出る | 待ち受けから待機画面まで約 0.1 秒(ログ「待機画面まで n秒」) | 画面(確認済み)/実機 |
| 起動確認 API が正しい形で答える | `BootAppTests` / `PageTests.test_healthの形` | 自動 |
| 多重起動が防止される | `LockTests`、2 回目の `start_app.py` が「すでに起動しています」で既存画面を開く | 自動/画面(確認済み) |
| 版が違えば古いほうを入れ替える | `test_版が違えば古いほうを止めて立て直す` | 自動 |
| 起動ファイルが CP932 / CRLF / chcp が先頭 | `test_launch_files` | 自動 |
| 起動失敗時にログ・案内を確認できる | Flask を外す → 起動エラー.html と start.bat の表示 | 実機 |

| 確認項目 | 方法 | 区分 |
|---|---|---|

| 選択・カテゴリ全選択/全解除・表示中の全選択/全解除・並べ替え・検索 | 画面操作 | 画面(確認済み) |
| フォルダ設定(存在しないフォルダは断る・保存して読み直す・既定に戻す) | `FolderSettingTests` | 自動 |
| 設定のタブ(点検表フォルダ / 管理者パスワード / 配布設定)・矢印キーで移動 | 画面操作 | 画面(確認済み) |
| 管理者パスワードの変更・既定に戻す・平文で持たない | `AdminPasswordTests` | 自動 |
| 配布設定の書き出し(パスワード必須・未設定の項目は入れない・作りかけを残さない) | `ExportTests` | 自動 |

## プレビュー

| 確認項目 | 方法 | 区分 |
|---|---|---|
| Excel を開ける・対象シートを取得できる・CopyPicture が実行できる | 点検表を選んでプレビュー | 実機 |
| 画像を取得できる・ブラウザへ表示できる | 同上(シート名・範囲が下部に表示される)/`PreviewTests` | 実機/自動 |
| 2 回目は控えの画像を出す | `test_プレビュー画像を作って返す` | 自動 |
| プレビュー後に Excel が残らない | タスクマネージャーで EXCEL.EXE が増えないこと(10 回連続) | 実機 |
| 通信手順・クリップボード失敗時の代替 | `test_excel_protocol` | 自動 |
| 印刷範囲に列 C～R を含む点検表 | VBA 版で失敗していた範囲でも表示されること | 実機 |

## 印刷

| 確認項目 | 方法 | 区分 |
|---|---|---|
| 1 件/複数件印刷できる・選択順に印刷される | 実際に印刷/`test_選んだ順に印刷して結果を返す` | 実機/自動 |
| 印刷部数が反映される(1～100、VBA 版と同じ丸め) | `ParseCopiesTest`、部数 2 で印刷 | 自動/実機 |
| Excel の印刷設定が維持される | 用紙・向き・余白・改ページ・ヘッダーが Excel から直接印刷した場合と同じ | 実機 |
| 印刷失敗時に通知される | `test_prints_in_selected_order_with_errors_reported`、プリンターをオフラインにして印刷 | 自動/実機 |
| 二重実行されない・中止できる・印刷中は終了を断る | `test_印刷中は二重に受けず_終了も断る` | 自動 |
| 進み具合(「2 / 10 …を印刷しています」)と帯の表示 | 画面操作 | 画面(確認済み) |

## ブラウザ(バックグラウンド・スリープ)

| 確認項目 | 方法 | 区分 |
|---|---|---|
| 裏に回ったタブ(タイマー停止)で 100 秒経っても終了しない | ブラウザで確認済み、`test_裏に回った画面は心拍が途切れても落とさない` | 画面/自動 |
| スリープ明け(gap 600 秒)で終了しない・待ち直す | ブラウザで確認済み、`test_スリープから戻ったら待ち直す` | 画面/自動 |
| 再読込では終了しない | ブラウザで確認済み、`test_再読込なら猶予のうちに戻って取り消される` | 画面/自動 |
| タブを閉じると 8 秒後に終了する | ブラウザで確認済み(9.1 秒で終了・ロック削除) | 画面 |
| 閉じた合図と裏の合図の順番が入れ替わっても終了する | `test_閉じた合図のあとに裏の合図が届いても閉じたまま` | 自動 |
| 印刷中は誰も見ていなくても終了しない | `test_印刷中は落とさない` | 自動 |
| 実際の PC スリープから復帰できる | PC をスリープ → 復帰後に画面が操作できる | 実機 |
| 接続が切れた場合に表示される | サーバー停止 → 赤い帯「バックエンドに接続できません」 | 画面(確認済み) |

## 停止

| 確認項目 | 方法 | 区分 |
|---|---|---|
| 正常終了できる | 画面の「終了」(確認済み)/stop.bat(確認済み) | 画面 |
| 接続を張ったままでも止まる(プロセスが残らない) | `test_接続を張ったままでも止まる` | 自動 |
| 対象アプリだけ停止できる・PID の使い回しで別のプロセスを止めない | `ProcessIdentityTests` | 自動 |
| 記録した子プロセスだけを片付ける | `test_記録した子プロセスだけを片付ける` | 自動 |
| Excel プロセスが残らない | 印刷中に stop.bat --force → EXCEL.EXE が残らない | 実機 |
| 停止理由がログに残る | `inspection_YYYYMMDD.log` の「終了しました」「誰も見ていないので終了します(…)」 | 画面(確認済み)/実機 |

## VBA 版との比較(Phase 14)

同じ点検表フォルダで、VBA 版と Python 版の次の項目が一致することを確認します。

- カテゴリー・サブカテゴリーの並び順、各タブに表示される点検表と表示名
- 「検出: n」の件数
- プレビューの範囲(シート・範囲)
- 印刷結果(用紙・向き・余白・ヘッダー/フッター)
