# デスクトップ版(Python/Tauri/Rust)の作り

VER2.0.0 から、ブラウザで開く代わりに**専用の窓(`InspectionSheet.exe`)**で動きます。
**ポートを使いません。** ブラウザ版(`Start.vbs` / `start.bat`)も予備として残してあります。
移行前に機能を1つずつ確かめた結果は [デスクトップ版_事前確認.md](デスクトップ版_事前確認.md)。
作りは移行済みの python-web-tools(梱包資材総合ツール VER4.0.0〜)と同じです。

## 何を何がするか(各言語が得意なことをする)

```
InspectionSheet.exe(Rust / Tauri)                 … src-tauri/
 ├─ 窓(WebView2)・終了の確認(印刷中です…)・フォルダーの選択窓
 ├─ 多重起動の防止・ブラウザ版との同時起動の防止(名前付きミューテックス)
 ├─ 画面の部品(/static/ の CSS・JS)を自分で返す
 ├─ Python を子として起動・監視(落ちたら理由の画面)
 └─ それ以外の要求(app://…)を Python の標準入力へ渡す
        │ 標準入出力(1件 = 見出し1行 + 本文)
        ▼
bridge.py(Python)                                 … ポート無しの入口
 └─ Flask アプリを WSGI として呼ぶだけ(待ち受けない)
        ▼
app/ ・ core/(Python)                              … 一覧・設定・ログ・Excel の段取り(ブラウザ版と同じもの)
        ▼
app/vbscript/excel_worker.vbs(VBScript)            … Excel の操作(今までどおり)
app/static/js(JS)                                  … 画面の操作(デスクトップ版のときだけ desktop.js)
```

| 担当 | 受け持ち | 理由 |
|---|---|---|
| **Rust** | 窓・起動と監視・多重起動/同時起動の防止・終了の確認・フォルダーの選択窓・部品の配信・理由の画面 | OS の窓・プロセス・錠を扱うのが得意。exe 1つで配れる。部品を Python に渡さないので画面が軽い |
| **Python** | 業務のすべて | **ブラウザ版と同じものを1つだけ持つ**ため。重い計算は無く(待ちは共有フォルダと Excel)、書き直しても速くならない |
| **VBScript** | Excel(開く・CopyPicture・PrintOut・閉じる) | 今までどおり。VBA と同じ言葉 |
| **JS** | 画面の操作 | 今までどおり |

## ポートを使わない仕組み

- 画面は独自の宛先 `app://localhost/`(Windows の WebView2 では `http://app.localhost/`)を読む。
  **ネットワークを通らない**(外枠の中で受ける名前)
- `/static/…`(CSS・JS)は外枠がファイルから直接返す(`src-tauri/src/statics.rs`)。控えの決まりは Flask と同じ
- それ以外は Python の標準入力へ渡し、標準出力から応答を受け取る(`src-tauri/src/bridge.rs` と `bridge.py`)
- 起動トークン・Host の確認・問い合わせ番号・ログは、ブラウザ版と同じものがそのまま働く
- 試験で確かめていること:
  - `tests/test_bridge.py`: ソケットを開くと落ちるようにして Python を起動しても、画面・一覧・プレビュー・印刷・終了が通る
  - `scripts/desktop_smoke.py`: exe を本当に起動し、窓に業務画面が届く・**どのプロセスもポートで待ち受けていない**・止めたら Python も終わる

## 同時に動かさない(どちらを後から開いても止まる)

| 先に動いているもの | 後から開いたもの | 動き |
|---|---|---|
| ブラウザ版 | デスクトップ版 | 「ブラウザ版が動いています。ブラウザの画面の『終了』で閉じてから、もう一度開いてください」と出して終わる(Python も起こさない) |
| デスクトップ版 | ブラウザ版(Start.vbs / start.bat) | 「デスクトップ版が動いています」と出して終わる。デスクトップ版の窓を前に出す |
| デスクトップ版 | デスクトップ版 | 開かず、開いている窓を前に出す |
| ブラウザ版 | ブラウザ版 | 今までどおり(開いているものにブラウザでつなぐ) |

- 錠は Windows の**名前付きミューテックス**(`Local\nlm.inspection-sheet-print.instance` ほか)。
  ラインPCの Python(Microsoft Store 版)はファイルの置き場所を振り替えるため、ファイルの錠では exe から見えない
- 利用者のログオンごとの錠なので、同じPCに別の人がリモートでログオンしていても止め合わない
- 落ちても OS が錠を外すので、残った錠で起動できなくなることは無い
- 手順は `core/instance_guard.py`(Python)と `src-tauri/src/instance.rs`(Rust)の2か所。名前は試験で突き合わせている

## 動きの約束

| 場面 | 動き |
|---|---|
| 起動 | 窓がすぐ出て「起動しています」→ 待機画面(段と進み具合)→ 業務画面 |
| 窓の × / 画面の「終了」 | 印刷中なら「印刷の途中です。中断して終了しますか?」と訊く。終わるときは Excel も閉じる |
| 点検表フォルダ・ログの保存先 | 「参照…」で Windows の「フォルダーの選択」窓(共有フォルダも選べる)。ブラウザ版はいままでの一覧から選ぶ |
| Python が見つからない・起動できない | 理由と次にすること(Python の入れ方・pip の打ち方)・ログの場所を窓に出す |
| Python が途中で落ちた | 窓を読み直して理由の画面を出す |
| exe を止めた | 標準入力が閉じるので Python も終わる(Excel も閉じる。取り残さない) |
| stop.bat | デスクトップ版は止めない(窓で閉じるよう案内し、窓を前に出す) |
| 模擬モード | `InspectionSheet.exe --demo`(Excel を使わずに画面を確かめる) |

Python は**同梱しません**。各PCに入っている Python を使います(`python.exe` → `py.exe -3` の順に探す。
`INSPECTION_PYTHON` で指定もできる)。デスクトップ版に要るパッケージは Flask だけです(waitress はブラウザ版用)。

## 作り方・配り方

**Windows 版は GitHub Actions が作ります**(`.github/workflows/desktop-windows.yml`)。
押すたびに、Python の試験・Rust の試験・exe の作成・exe を起動しての確認(同時起動の防止の両方向を含む)まで流れ、
成果物 `InspectionSheet-windows` に `InspectionSheet.exe` が入ります。

配るとき:

1. `InspectionSheet.exe` を、アプリのフォルダ(`bridge.py` がある所)の**直下**に置く
2. デスクトップにショートカットを作る(exe そのものをコピーしない)

**入れ替えるとき**: 共有フォルダの exe は、どこかのラインで動いているあいだは上書きできません
(Windows が使用中のファイルを守る)。動いている exe も**名前を変えることはできる**ので、
`InspectionSheet.exe` を `InspectionSheet.old.exe` に名前を変えてから新しい exe を置きます。
各ラインは次に開いたときから新しい exe になります(古いものは全員が閉じたあとで消す)。
Python 側(app/・core/)は今までどおり入れ替えられます(動いている版には「新しい版が置かれました」の帯が出る)。

手元で作るとき(開発機):

```
cd src-tauri
cargo build --release            # target/release/InspectionSheet(.exe)
python ../scripts/desktop_smoke.py --exe target/release/InspectionSheet    # Linux は xvfb-run を前に付ける
```

Linux で作るには WebKitGTK が要ります(`libwebkit2gtk-4.1-dev` など)。

## 置き場所の決まり

- exe は `bridge.py` と同じフォルダに置く(上の階層もたどるので、`src-tauri/target/...` から動かしても見つかる)。
  `INSPECTION_ROOT` で指定もできる
- 版は `config/app.json`・`src-tauri/tauri.conf.json`・`src-tauri/Cargo.toml` の3か所。食い違うと試験が落ちる
- アイコンは `scripts/make_desktop_icon.py` で作る(`src-tauri/icons/`。作るときだけ Pillow が要る)

## 確かめきれていないこと(Windows の実機で見る)

確認は Linux(WebKitGTK)の上で窓を実際に動かして行い、Windows では GitHub Actions が
「起動して業務画面が届く・待ち受けない・同時起動を両方向で止める・止めたら Python も終わる」まで確かめます。
次は**実機で人が見る**必要があります:

- Excel の実物でのプレビュー・印刷(VBScript の部分は変えていないが、窓の中から通しで)
- 窓の × で、印刷中に確認が出ること
- 「参照…」で Windows の「フォルダーの選択」窓が開き、共有フォルダを選べること
- Ctrl+P で点検表の印刷が始まる(WebView2 の印刷が出ない)こと
- ログの「文にして写す」(クリップボード)・「フォルダを開く」
- **Microsoft Store 版の Python で、ブラウザ版とデスクトップ版が互いに止め合うこと**
  (Actions の Windows は python.org 版の Python。Store 版でも名前付きミューテックスは振り替えられない作りだが、実機で一度見る)
