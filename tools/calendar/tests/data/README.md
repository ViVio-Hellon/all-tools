# テスト用フィクスチャ

`sample.accdb` は Access リーダ (`calendar_app/accdb/reader.py`) の検証に使う
実物の Access 2007+ (ACE) 形式ファイルです。

**このファイルは匿名化済みです。**
元データには実在の従業員氏名・Windows ユーザー名・PC 名が含まれていたため、
次の処理を行っています。

1. 全データページから「生きている行」以外のバイトをゼロ埋め
   (削除済み行のスラック領域に氏名・PC 名・コメントが残っていたため)
2. 生きている行に残る値を、**同じ文字数**の架空の値へ置換
   (UTF-16LE で文字数が同じなら可変長オフセット表が変わらないため、
   ファイル構造はそのまま保たれる)

置換後も `mdb-export` で同じ内容が読め、
全 24 テーブル (システムテーブル含む) について
テーブル定義の行数と実際に読める行数が一致することを確認しています。

## 収録内容

| テーブル | 行数 |
|---|---|
| 休み管理 | 2 |
| 削除履歴 | 2 |
| システムテーブル (MSys*) | 20 テーブル |

`班員名簿` はマスタ DB (梱包資材マスタ.accdb) 側のテーブルのため含まれていません。
そのため取り込みテストでは「見つからなかったテーブル」として扱われることを検証しています。
