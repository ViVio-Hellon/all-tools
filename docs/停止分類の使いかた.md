# 停止分類の使いかた

日報管理ツールの**停止**(作業停止①〜⑤に打つ記号と時間)が、どう分けられ、どこに数えられるかの説明です。
停止理由の一覧(停止内訳)を直す人と、集計を読む人のための文書です。

細かい理由はコードの場所(`tools/nippou/` から見た場所)と、`tools/nippou/README.md` の版の節に書いてあります。

---

## 1. 2つの分け方 ── 「停止分類」と「集計の種類」

停止には**別々の2つの分け方**があります。名前が似ているので取り違えないでください。

### 停止分類(選ぶときの並び)

日報入力で記号を選ぶ欄は、分類ごとにまとめて並んでいます。分類は**停止内訳の表(伝送用ファイルの
`作業停止時間内訳_1/_2/_3`)か、停止内訳 CSV の「分類」の欄**で決まります(`logic/stop_csv.CATEGORIES`)。

| 分類 | 画面の分類名 | 表の名前 | 呼び名 | 記号の文字の種類(決まり) |
|---|---|---|---|---|
| 1 | 設備停止 | `作業停止時間内訳_1` | 管理ロス | 数字 |
| 2 | 不稼働 | `作業停止時間内訳_2` | 突発・待ち | 片仮名 |
| 3 | ハンドリング | `作業停止時間内訳_3` | ハンドリング | 英字 |

### 集計の種類(数えるときの分け方)

集計(集計管理・集計グラフ・CSV・共有へ送る集計)は、**記号の文字の種類**で分けます(VBA の
`CheckCharType` と同じ。`logic/aggregation.stop_kind_of` の1か所)。どの分類の表に書いたかは見ません。

| 記号 | 集計の種類 | 画面・CSV での名前 | 止まっていた時間(停止合計)に入るか |
|---|---|---|---|
| 数字(99 をのぞく) | 管理ロス停止 | 管理ロス設備停止(表の列は「管理ロス」) | 入る |
| 片仮名 | 突発停止 | 段取り・突発停止(表の列は「突発」) | 入る |
| 英字 | ハンドリング停止 | ハンドリング停止 | 入る |
| **分類1・内訳番号99** | **その他停止** | その他停止(表の列は「その他」) | 入る |
| どれにも当たらない(数字と片仮名が混ざる など) | その他 | その他 | **入らない** |

- 稼働時間 = 1440分 − 止まっていた時間(上の「入る」ものぜんぶ)。稼働率 = 稼働時間 ÷ 1440分 × 100。
- 操業時間 = 1440分 − 管理ロス − その他停止(99)。99 も管理ロスに数えていたころと同じく引きます。突発とハンドリングは引きません。
- 作業時間は日報に打った作業時間の合計で、停止はどれも作業時間には入りません。

### 分類と記号の文字の種類が食い違うと

停止内訳 CSV で、分類と記号の文字の種類が合わない行(例: `2,5,…` ── 分類2なのに数字の記号)は、
**読んで使いますが注意を出します**。設定・管理者 → マスタ → 停止内訳 の「使っていますが、確かめてください」に
「突発・待ちの記号は片仮名です。「5」は集計で管理ロスに数えられます」のように出ます。
選ぶときは分類2の中に並び、集計では記号の文字どおり管理ロスに数えられる、ということです。

## 2. 特殊な記号 ── 分類1・内訳番号99

**休憩の延長を打つための記号**です(超えた分をほかの停止や作業時間に足して打たないように)。

| こと | 決まり |
|---|---|
| 名前(内訳) | **空白でよいのはこの記号だけ**です。CSV は `1,99,,` / `1,99` と書けます。ほかの記号は「内訳(理由の名前)がありません」で使いません |
| 画面 | 選ぶ欄・全停入力・設定の一覧では「99(名前なし)」と出ます |
| 集計の名前 | 空白のまま入ります |
| 集計の種類 | 数字の記号ですが、**管理ロスに数えず「その他停止」**に数えます |
| 止まっていた時間 | **入ります**(停止合計・稼働時間・稼働率・操業時間は、管理ロスに数えていたころと1分も変わりません) |
| 作業時間 | 入りません(ほかの停止と同じ) |
| 休憩の確かめ(60分) | 数えません(休憩は記号 0 だけ) |

決まりの1か所は `logic/aggregation.OTHER_STOP_CODES` です。「名前が空でよい記号」(`logic/stop_csv.BLANK_LABEL_OK`)も
ここから作っています。

### 出口ごとの 99 の扱い

画面の中と、このツールが書き出す CSV では「その他」に分けます(集計_ CSV と停止内訳_ CSV で数が食い違わない
ように)。**共有へ送る集計の表**(欄が「管理ロス・突発・ハンドリング」に決まっていて、VBA・Access・ほかの人の
Excel が読むもの)だけは、**形を変えず、今までどおり 99 を管理ロスの欄に入れて**出します。

| 出口 | 99 の扱い |
|---|---|
| 集計管理(直別の表・その CSV `集計_直別_…`) | 「その他」の列 |
| 集計・グラフ(停止の内訳(分類)の輪・直別集計・直の実績の確認) | 「その他停止」の扇・「その他」の列 |
| 停止の項目(グラフの表・停止内訳_ CSV・月の書き出しの 〜_停止集計.csv) | 分類の欄が「その他停止」 |
| 印刷(「紙には無い、このツールの追加」の集計) | 99 のある直だけ「その他(分)」の行が出る |
| 途中式(稼働率などの式) | 99 のある直だけ「+ その他」が出る |
| 集計_ CSV・月の書き出しの 〜_集計.csv | 「その他(分)」の欄(**v4.44.14 から増えた欄**。ハンドリング停止(分)の次・停止合計(分)の前) |
| 共有へ送る集計 `T_日報集計_<ライン>` | **「管理ロス停止分」に入ったまま** |
| 共有へ送る停止 `T_日報停止明細_<ライン>` | **分類の欄は「管理ロス停止」のまま** |
| 共有の日報(見出し・明細) | 記号 99 と時間がそのまま入る(分類の欄はありません) |

- 集計_ CSV は列が1つ増えました。**列の位置で読んでいる Excel などは、停止合計(分)から右が1つずれます。**
  見出しの名前で読んでいれば影響はありません。
- 共有へ出る中身は前と同じなので、99 を分けたことで送り済みの直が「未送信」に戻ることはありません
  (`logic/packing_agg.fixed_columns`)。
- 分ける前に作った集計(99 が管理ロスのまま残っている直)は、集計を読むときにその直だけ作り直します
  (`services/summary.fill_missing`)。設定・管理者の「集計を作り直す」でも分かれます。

## 3. 停止内訳の直し方

停止内訳(停止理由の一覧)は、**メモ帳で直せる CSV(`停止内訳.csv`)**と、**伝送用ファイルの表
(`作業停止時間内訳_1/_2/_3`)**の2か所から読みます(`access_bridge/stop_master`)。

| こと | 決まり |
|---|---|
| CSV の置き場所 | 既定は参照用マスタと同じフォルダの `停止内訳.csv`。設定・管理者 → 参照パス の「停止内訳の置き場所」で変えられます(管理者パスワードが要ります) |
| どちらを使うか | **分類ごとに、CSV に行があれば CSV、1行も無い分類は表**。重ねません(CSV から消した理由が表から戻ってこないように) |
| 鍵 | 見本を出す・CSV から読む・読み直すは**管理者パスワード無しで**押せます |
| いつ効くか | 次に日報入力を開いたときから |
| 配布 | 「停止内訳の置き場所」は配布設定で配れます(`docs/アクセス権限と配布設定.md`)。共有のフォルダを指せば全端末が同じ一覧を使います |

### 書き方

```
# 行頭 # は覚え書き。空行は飛ばします
分類,内訳番号,内訳,備考
1,0,休憩食事,
1,99,,
2,イ,突発停止(機械),
3,A,段取り変更,
```

- 分類は `1` / `2` / `3`。「設備停止」「管理ロス」「作業停止時間内訳_1」のような呼び名でも読みます。
- 内訳番号(記号)は**書いたとおりに**使います(全角半角も変えません)。昔の日報に残っている記号と
  1文字でも違うと、昔の日報の停止が「停止内訳にない記号」になります。
- 記号は**分類をまたいで1つずつ**。同じ記号の2つ目の行は使いません。
- 区切りは「,」(Excel で保存したもの)でもタブでもかまいません。

### 読めない行の出方

読めない行は**黙って捨てません**。設定・管理者 → マスタ → 停止内訳 に行番号つきで出ます。

| 出る所 | 例 |
|---|---|
| 使えなかった行があります(その行は使わない) | 欄が足りません / 分類「4」が分かりません / 内訳番号(記号)がありません / 内訳(理由の名前)がありません / 記号「イ」は 3行目(突発・待ち)と同じです |
| 使っていますが、確かめてください(使う) | 分類と記号の文字の種類が合わない(1章) |

### 見本・渡す・読み直す(設定・管理者 → マスタ → 停止内訳)

1. **「見本を出す」** … いま使っている一覧を CSV に書き出します。ファイルがまだ無ければ `停止内訳.csv`、
   既にあれば上書きせず隣に `停止内訳.見本.csv` を作ります。
2. **「CSV から読む」** … 書き換えたファイルを渡すと、増える・消える・名前が変わる理由を先に見せます。
   **「決定」を押すまで書きません**。決定すると `停止内訳.csv` を書き換え、前のファイルは `停止内訳.前回.csv` に残します。
3. **「いまの CSV を読み直す」** … メモ帳で直したあと、効いたかどうかをここで確かめます。

## 4. 集計で見る所

### 集計管理(表)

| 表 | 停止について出るもの |
|---|---|
| 日別の集計 | 停止(分) = その日の止まっていた時間の合計 |
| 直別の集計 | 管理ロス / 突発 / ﾊﾝﾄﾞﾘﾝｸﾞ / **その他** / 稼働(分) / 操業(分)。管理ロス + 突発 + ﾊﾝﾄﾞﾘﾝｸﾞ + その他 = 1440 − 稼働 |
| ロット・用途・納入先ごと | 停止(分)と停止の内訳(記号・名前・分・回数) |
| ロット一覧 | 作業停止(行ごとの記号・名前・分) |

「4本ともCSVに出す」は、画面の表をそのまま `集計_<表>_<開始日>_<終了日>_<ライン>.csv` に書きます。

### 内訳番号99 の時間(集計管理の中。**管理者だけ**)

管理者モードか、アクセス権限の表で Administrator の PC のときだけ、集計管理に「内訳番号99 の時間」の面が出ます。
ほかの端末には面が無く、サーバも答えません(`presenters/code99.py`・`app/routes/agg.py`)。
面は**開いたときに読みます**(読めるラインの控えをぜんぶ読むため)。

| 表 | 中身 |
|---|---|
| ライン別 | 読めるラインごと(Administrator の PC は控えのあるライン、ほかはこの端末のライン)。回数・合計(分)・打った直・保存のある直・1直あたり(分)・最初に打った日・その日から(日) |
| 直別 | 上で選んでいるラインの 1直・2直・3直・日勤ごと |
| 作業者別 | 日報の作業者の欄から。**複数人の直は全員に同じ分を数えます**(作業者別の合計はライン全体より多くなることがあります) |
| 月ごとの移り変わり | 月ごとの合計と、前の月との差 |

- 開始日を空にして「表示」を押すと、**使い始めた月の1日**からになります。最初に 99 が打たれた日と、
  その日から今日までの日数も出ます。
- 数は集計管理の直別の「その他」と同じものです(打った日報から、集計と同じ並べ方で数えます)。
- 「4本ともCSVに出す」は `集計_内訳番号99_ライン別_…` / `_直別_…` / `_作業者別_…` / `_月ごと_…` の4本です。

### 集計・グラフ

- **停止の内訳(分類)** … 管理ロス設備停止(青)/ 段取り・突発停止(赤)/ ハンドリング停止(橙)/ その他停止(灰)の輪。
- **停止の項目ごと** … 記号ごとの輪と表(長い順)。表の「分類」に種類が出ます。
- **直別集計** … 管理ロス / 突発 / ﾊﾝﾄﾞﾘﾝｸﾞ / その他。

### CSV の欄

| CSV | 欄 | 入るもの |
|---|---|---|
| `集計_<日付>_<ライン>.csv`・月の `〜_集計.csv` | 管理ロス設備停止(分)/ 段取り・突発停止(分)/ ハンドリング停止(分)/ その他(分)/ 停止合計(分) | 4つの欄の和 = 停止合計 = 1440 − 稼働時間合計。**99 は「その他(分)」に入ります**(停止内訳_ の「その他停止」と同じ数)。「その他(分)」は v4.44.14 から増えた欄です |
| `停止内訳_<日付>_<ライン>.csv`・月の `〜_停止集計.csv` | 分類 | 管理ロス設備停止 / 段取り・突発停止 / ハンドリング停止 / その他停止 / その他 |
| 同上 | 記号 / 内訳 | 打った記号と、その名前(99 は名前が空) |
| `集計_<日付>_<ライン>.csv`・月の `〜_集計.csv` | 操業時間(分) | 1440 − 管理ロス設備停止 − その他 |

CSV の欄の説明は、書き出したフォルダの `CSVの読み方.txt` にも出ます(`reporting/csv_legend.py`)。

## 5. よくある問い

**分類4は作れますか?**
作れません。CSV の分類は 1・2・3 だけで、ほかは「分類「4」が分かりません」で使いません。伝送用ファイルの表も
`作業停止時間内訳_1〜3` の3つで、共有へ送る集計と VBA の欄も3つです。集計の種類は記号の文字で決まるので、
分類を増やしても数え方は分かれません。新しく分けて数えたい記号があるときは、99 と同じ決まり
(`logic/aggregation.OTHER_STOP_CODES`)に足すことになります(ツールを直す話です)。

**記号を変えたら昔の日報はどうなりますか?**
昔の日報に残っている記号は変わりません。一覧から消えた記号は「停止内訳にない記号」になり、その直を
保存し直すときの確かめで止まります。「CSV から読む」の下見で、消える記号を先に確かめてください。
集計の種類は記号の文字で決まるので、名前を変えても数え先は変わりません。

**全角の「９９」で書いたら?**
CSV でも日報でも 99 とみなします(名前が空でよい・その他停止に数える)。記号そのものは書いたとおり残ります。

**99 に名前を付けたら?**
名前を付けても「その他停止」に数えます(決まりは記号で見ます)。名前は集計の名前の欄に入ります。

**99 を分類2や3に書いたら?**
読んで使いますが、注意が出ます(「…「99」は集計でその他停止に数えられます」)。数え先は分類1に書いたときと同じです。

**紙の「その他(理由を記載)」とは同じものですか?**
別のものです。「その他(理由を記載)」は理由の欄を開けるための停止理由で、集計の種類はその記号の文字で決まります。
集計の「その他停止」は分類1・内訳番号99 だけです。
