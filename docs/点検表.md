# 点検表 選択・印刷(VER2.4.13)

共有フォルダにある点検表(Excel・Word)を画面で探して選び、部数を決めて、選んだ順にまとめて印刷するツールです。印刷の前にプレビューで中身を確かめられます。Excel VBA の「シート印刷管理」フォーム(UFPrintManager / UFPreview)を Python に移したもので、点検表そのものは Excel・Word のファイルのまま使います。

## 仕様

### 開き方と動く形

| 形 | 説明 |
|---|---|
| デスクトップ版(ふだん) | 日報複合ツール.exe の窓の上の大きなタブ「点検表」で開きます。ポートを使いません。 |
| ブラウザ版(予備) | このツールのフォルダの `Start.vbs`(起動)・`start.bat`(診断起動)・`stop.bat`(停止)。 |
| 同時には動かない | 2つの形は同時に動きません。後から開いたほうが理由を出して止まります。 |
| 模擬モード | `start.bat --demo`。Excel を使わずに画面を確かめます(下の「モード説明」)。 |

- 動作環境: Windows のラインPC。Excel が要ります。Word の点検表を使うなら Word も要ります。
- Python 3.9 以上と Flask(ブラウザ版で動かすときは waitress も)。各PCに入っているものを使います(同梱しません)。一覧は [日報複合ツール.md](日報複合ツール.md) の「必要なもの」。Excel・Word は pywin32 を使わず cscript + VBScript で動かし、プレビュー画像は ctypes と標準ライブラリで作ります(Pillow は要りません)。

### 画面の一覧

| 画面 | 出るとき | おもな中身 |
|---|---|---|
| 起動待機画面 | 起動したとき | 段(実行環境 → 準備 → 点検表フォルダ → 完了)と進み具合 |
| 主画面 | ふだん | 上の帯、左に点検表の一覧、右に「選択中」・印刷部数・プレビュー・印刷 |
| 上の帯 | 主画面の上 | 選択・検出の件数、更新時刻、点検表フォルダ、再読込、設定、明るさ、終了 |
| 点検表の一覧(左) | 主画面 | カテゴリーのタブ > サブカテゴリー > 点検表。検索の欄、まとめて選ぶボタン |
| 選択中(右) | 主画面 | 選んだ順の一覧。行ごとに ◧(プレビュー)・↑・↓・×、「すべて解除」 |
| プレビュー | 「プレビュー」または ◧ を押したとき | 左に選んだ点検表、真ん中に中身。全体表示 / 実寸表示・作り直す・閉じる |
| 印刷の確認 | 「印刷」を押したとき | 件数・部数・プリンター名。「印刷する」/「キャンセル」 |
| 印刷中・印刷完了 | 印刷のあいだと後 | 「2 / 4 台車点検を印刷しています」、1件ずつの印(✓ ● – ✕)、中止、問い合わせ番号 |
| 設定 | 帯の「設定」 | 点検表フォルダ・管理者パスワード・配布設定・ログの4つの面 |

### 扱うファイル

| 種類 | 拡張子 | 開くアプリ |
|---|---|---|
| Excel の点検表 | .xlsx / .xlsm / .xls | 非表示の Excel |
| Word の点検表(VER2.3.0 から) | .docx / .docm / .doc | 非表示の Word |

- 開くアプリは拡張子で決めます。
- `~$` で始まる一時ファイル(Excel・Word のロックファイル)は一覧に載せません。
- 拡張子は `config/inspection.json` の `extensions` で決めています。前の版の既定(xlsm / xlsx / xls だけ)のままなら、Word の3つも足して読みます。

### 置き場所

| もの | 場所 |
|---|---|
| 点検表 | 共有フォルダ(点検表ルートフォルダ)。既定の場所は `config/inspection.json` の `root_folder` |
| アプリ本体 | 共有フォルダでも各PCへのコピーでもよい。どのPCも本体のフォルダへは書きません(例外は配布設定の書き出し) |
| 利用者の設定 | `%LOCALAPPDATA%\InspectionSheetPrint\data\user_settings.json`(利用者ごと・PCごと) |
| ログ・プレビューの控え・ロック | `%LOCALAPPDATA%\InspectionSheetPrint\` の下(ログは `logs\inspection\`)。ログの保存先は設定で共有フォルダにもできます。どちらでも `<保存先>\inspection\` の下に `inspection_` で始まる名前で書きます(`inspection_YYYYMMDD_<PC>_<利用者>.log`・`inspection_events_YYYYMMDD_<PC>_<利用者>.jsonl`。この PC では `_<PC>_<利用者>` なし) |
| 配布設定 | アプリのフォルダの直下の `配布設定\設定.json` |

> 日報複合ツールでは、大設定の「4ツールの分もまとめて書き出す」で、このツールの配布設定が大設定の `配布設定\日報複合ツール.json` にも入ります(この1つのファイルだけでも届きます)。このツールのフォルダの配布設定と両方あるときは、**作った時刻が新しいほう**を丸ごと使います(同じならこのツールのフォルダのほう)。中身は大設定の「配布設定」の「各ツールの配布設定(中身)」で確かめられます(詳しくは `docs/日報複合ツール.md` の「配布設定」)。

### ラインごとの一覧の作り方

一覧はフォルダの形とファイル名から自動で作ります。

```text
点検表ルートフォルダ
└─ カテゴリー のフォルダ(例: 梱包)          … 上のタブになる
   └─ サブカテゴリー のフォルダ(例: 日常点検) … 左の見出しになる
      └─ 梱包_日常点検_台車点検.xlsx          … 一覧には「台車点検」と出る
```

- ファイル名は「カテゴリー名_サブカテゴリー名_点検表の名前」にします。大文字小文字は問いません。
- この形でないファイルは一覧に出ません。一覧のいちばん下の「命名規則に合わないため表示していないファイル」で確かめられます。
- カテゴリー・サブカテゴリーは名前の昇順(大文字小文字を区別しない)に並びます。
- ラインごとに別の点検表フォルダを使うときは、そのPCの「設定」→「点検表フォルダ」で決めます。この指定は配布設定で上書きされません。
- 起動したときは前回の一覧をすぐ出し、共有フォルダの確認は裏で続けます。確認が終わると新しい一覧に替わります。

### プレビュー・印刷の仕組み

Excel・Word は画面には出さず、裏で動かします。Python から Windows 標準の `cscript.exe` で `app/vbscript/excel_worker.vbs` を動かし、COM で Excel・Word を操作します。Python とのやり取りは標準入出力だけで、ファイルは受け渡しません。

| | Excel の点検表 | Word の点検表 |
|---|---|---|
| 開き方 | 読み取り専用・通知なし。保存せずに閉じる | 読み取り専用・最近使ったファイルに載せない。保存せずに閉じる |
| プレビュー | 最初の表示シートの印刷範囲を `CopyPicture` で絵にして出す。印刷範囲が無ければ使っている範囲(最大 40 行 × 16 列)、それも無ければ A1:P40 | `ExportAsFixedFormat` で PDF にして画面の中に出す。全ページ(既定は先頭 20 ページまで)。PDF にできないときだけ 1ページ目の絵 |
| 印刷 | 最初の表示シートを `PrintOut`。印刷範囲・用紙・余白は Excel の設定のまま | `PrintOut`(刷り終わるまで待つ)。用紙・余白は文書の設定のまま |
| アプリの使い回し | 使い回す。処理のあとも 120 秒残し、使われなければ閉じる | 使い回さない。処理のたびに終える |
| 自分で開いた文書との関係 | 裏の Excel は利用者がダブルクリックしたファイルを受け取らない(`IgnoreRemoteRequests`) | 利用者の文書が裏の Word で開いたら、Word を見せて残し、その文書は閉じない |

- プレビューの絵・PDF は控えておき、ファイルの更新日時が同じなら2回目からすぐ出します。
- 印刷は Windows の既定のプリンターに出ます。既定のプリンターが替わっていたら、Excel を起動し直してから印刷します。
- 1回の印刷は選んだ順に1件ずつ処理します。1件で一定時間(既定 180 秒)応答が無ければ、その Excel と cscript だけを止め、残りは「中止」として出します。
- 開いた点検表のマクロは既定で動かしません(Excel)。パスワード付きのブックは入力待ちにせず「開けませんでした」と出します。
- Word が途中で終わったとき(エラー 462 など)は、Word を起こし直して1回だけやり直します。印刷の途中で終わったときは、紙に出ているかもしれないのでやり直しません。
- Word を起動できなくても、同じ印刷の Excel の点検表は刷ります。

既に開いていた場合の扱い(VER2.3.2 から):

| 状況 | 扱い |
|---|---|
| この PC の Excel・Word で、その点検表が開いたまま | 保存せずに閉じてからプレビュー・印刷します。閉じるのはそのファイルだけです。閉じたことは画面とログに出ます(`excel.close_open_copy` で止められます) |
| ほかの PC で開かれている | 閉じられません。読み取り専用で開くので、そのまま印刷・プレビューできます。名前が読めれば「○○さんが開いたままです(印刷はできます)」と出します |
| 利用者が自分で開いている Excel | このアプリが起動した Excel ではないので、触れません。終了もさせません |
| 起動した Word が利用者の Word だった | 隠さない・設定を戻す・終えない |

## 操作説明

### 毎日の操作

1. 日報複合ツールの上の大きなタブの「点検表」を押します。はじめは「点検表フォルダを確認しています」と出ることがあります。少し待つと一覧が出ます。
2. **探す**: 上のカテゴリーのタブを押し、左のサブカテゴリーを押します。名前で探すときは、検索の欄に名前の一部を入れます(全部のカテゴリーから探します。Esc で消えます)。
3. **選ぶ**: 印刷したい点検表を、印刷したい順に押します。チェックと番号(1・2・3…)が付き、右の「選択中」に同じ順で並びます。もう一度押すと外れます。タブを切り替えても選んだものは残ります。
4. 順番を直すときは「選択中」の行の ↑ ↓ を押します。外すときは ×、全部外すときは「すべて解除」です。
5. **部数**: 「印刷部数」を ＋ − か数字で決めます(1〜100)。選んだ点検表のどれもこの部数ずつ印刷します。
6. **プレビュー**: 「プレビュー」を押すと、プレビューの画面に移ります。この時点では何も作りません。左の一覧から見たい点検表を押すと、その点検表だけを作って出します。
   - 「選択中」の行の ◧ で開いたときは、その点検表がすぐに出ます。
   - ↑ ↓ キーで前・次の点検表に切り替えられます。何も選んでいないときは ↓ で1件目、↑ で最後の点検表が出ます。
   - はじめて見る点検表は数秒〜十数秒かかります。2回目からはすぐに出ます。
   - Excel は絵を押すか「全体表示」で、全体表示と実寸表示が切り替わります。Word は PDF の表示でスクロール・拡大縮小します。
   - 点検表を直したのに古い絵が出るときは「作り直す」を押します。
   - 確かめたら「閉じる」を押します。
7. **印刷**: 「印刷」を押すと「印刷の確認」が出ます。件数・部数・プリンター名を確かめて「印刷する」を押します。プリンターがちがうときは「キャンセル」して班長に知らせます。
8. 「印刷中...」の画面で、選んだ順に1件ずつ印刷します。やめるときは「中止」を押します。いま印刷している1件が終わってから止まります。
9. 「印刷完了」と出たら、紙が出ているか確かめて「閉じる」を押します。「印刷完了(エラーあり)」のときは、✕ の付いた点検表は印刷されていません。問い合わせ番号を控えて(写真でもよい)班長・管理者に伝えます。

- 1件も選んでいないときは、プレビューと印刷は押せません。
- 印刷中は、選び直し・再読込・設定はできません。印刷は同時に1つだけです。

### まとめて選ぶ・読み直す

| ボタン | すること |
|---|---|
| 表示中を全選択 / 表示中を全解除 | いま一覧に出ている点検表(開いているサブカテゴリー、または検索結果)を全部選ぶ / 外す |
| カテゴリ全選択 / カテゴリ全解除 | いまのカテゴリーの中を、サブカテゴリーもふくめて全部選ぶ / 外す(検索中は押せません) |
| 再読込(帯) | 点検表フォルダを読み直す。点検表を足した・消した・名前を変えたときに押す |

### 設定(班長・管理者)

1. 帯の「設定」を押します。ライン作業者はふだん触りません。
2. **点検表フォルダ**: 点検表の親フォルダを入れるか、「参照…」で選びます。「保存して読み直す」で決まります。「既定に戻す」で最初の場所に戻ります。パスワードは要りません。
3. **管理者パスワード**: いまのパスワードと新しいパスワード(4文字以上)を入れて「パスワードを変える」を押します。
4. **配布設定**: 入れる項目にチェックを付け、管理者パスワードを入れて「配布設定を書き出す」を押します。ほかのラインのPCは次に開いたときに読み込みます。そのPCで自分で決めてある項目は上書きしません。そろえたいPCでは「配布設定を読み込み直す」を押します。やめるときは「配布設定を消す」です。
5. **ログ**: 問い合わせ番号を入れて「探す」を押すと、なぜなぜ(現象 → 何が起きたか → 詳しい原因)とそのときの状況が出ます。「文にして写す」でメールや Teams に貼れます。ログの保存先・保存日数もここで決めます。
6. 終わったら右下の「閉じる」を押します。

画面の明るさは、帯のボタンを押すたびに「☀ ライト → ☾ ダーク → ◇ 既定」と変わります。「◇ 既定」は日報複合ツールの大設定の「画面の色の既定」に合わせます。

### 終わるとき

1. 「印刷中...」の画面が出ていないことを確かめます。
2. 日報複合ツールの右上、または点検表の帯の「終了」を押します。日報複合ツール全体が閉じます。
3. 印刷の途中なら「中断して終了しますか?」と聞かれます。ふつうは「キャンセル」して、終わるのを待ちます。

## 思想(設計の考え方)

- **点検表はファイルのまま使う。** HTML などへは変換しません。印刷範囲・用紙・余白は Excel・Word に決めてあるとおりに使います。
- **点検表は原紙。読むだけで、書き換えない。** 読み取り専用で開き、保存せずに閉じます。ロックも取りません。この PC で開いたままの原紙は、保存せずに閉じてから刷ります(編集の要らない、印刷するだけのものだからです)。
- **VBA 版の決まりを守る。** 一覧の作り方・プレビュー範囲の決め方・Word の印刷の手順は VBA 版と同じです。VBA 版で印刷できていたものは、同じ手順に戻して直します(VER2.4.1)。
- **変えるのは理由があるところだけ。** 意図して変えた点と理由は次のとおりです。

| 項目 | VBA 版 | いまの版 | 理由 |
|---|---|---|---|
| 印刷順 | チェックボックスの作成順 | 選んだ順(並べ替えできる) | 要件定義書 14.2 |
| 全選択 / 解除 | 1つのボタンで切り替え | 「全選択」「全解除」を分けた | 一部だけ選んでいると反応しない分かりにくさをなくす |
| 印刷前の確認・中止 | なし | 件数・部数・プリンターを確認。1件ずつ中止できる | 大量の誤印刷を防ぐ |
| マクロ・パスワード付きブック | マクロが動く・入力待ちになる | マクロは止める・「開けませんでした」 | 非表示の Excel で窓が出ると止まるため |
| 命名規則に合わないファイル | 黙って出ない | 出さないが、件数と一覧を出す | 原因を追えるようにするため |
| プレビュー | 毎回作る | 更新日時が同じなら控えを出す | 2回目から速くするため |

- **利用者のものには触れない。** 利用者が自分で開いた Excel・Word、ほかのアプリの Excel は止めません。片付けるのは、このアプリが起動して記録したもの(PID と生成時刻で本人確認)だけです。
- **複数ラインで壊し合わない。** 本体は共有しても読むだけにし、ロック・ログ・控え・設定はPCごと・利用者ごとに分けます。配布設定は、その端末ですでに決めてある項目を上書きしません。
- **エラーは後から辿れるようにする。** 断りの文・印刷の結果には問い合わせ番号を出し、ログからなぜなぜを辿れます。記録に失敗しても印刷は止めません。
- **同じ現場の道具と作法をそろえる。** 起動・多重起動防止・待機画面・停止・画面の帯や色は python-web-tools(梱包資材総合ツール)と同じにしています。並べて使うので、覚えることを増やしません。
- **版は現場が何をし直すかで上げる。** 手順が変わればメジャー、できることが増えればマイナー、直しただけならパッチです。迷ったら大きいほうへ寄せます。

## モード説明

点検表は、梱包資材マスタの「アクセス権限」表を読みません(`portal/access_guide.py` で、点検表の欄はどの値も「読まない」です)。ログインID・PC名で使える機能は変わりません。区別は次の管理者パスワードと模擬モードだけです。

| 名前 | なれる人・なり方 | できること | できないこと |
|---|---|---|---|
| ふだんの利用(ライン作業者) | だれでも。点検表のタブを開くだけ | 探す・選ぶ・並べ替え・部数・プレビュー・印刷・中止・再読込・明るさの切り替え | 配布設定の書き出し・読み込み直し・消去、管理者パスワードの変更 |
| 班長(設定の操作) | 帯の「設定」を開く。パスワードは要らない | 点検表フォルダの変更・既定に戻す、ログを番号で探す、ログの保存先・保存日数の変更 | 配布設定の操作、管理者パスワードの変更 |
| 管理者(管理者パスワード) | 管理者パスワードを知っている人。操作のたびに入れる | 上のすべてに加え、配布設定の書き出し・読み込み直し・消去、管理者パスワードの変更 | 印刷中に設定を開くこと(ほかの人と同じ) |
| 模擬モード | ブラウザ版を `start.bat --demo` で起動する | 見本フォルダで画面を確かめる。プレビューは仮の画像、印刷は模擬の動き | 本当の点検表のプレビュー・印刷(Excel を使わない) |

- 管理者パスワードは、1台の操作で全ラインの設定が変わる配布設定を誤って押さないための確認です。だれが端末を使えるかを決めるものではありません。
- 一度も変えていない端末は、梱包資材総合ツールと同じ既定の値で通ります。値は撹拌して保存し、平文では持ちません。
- 管理者パスワードをライン作業者に教えたり、パソコンに貼ったりしないでください。

## 用語

| 用語 | 意味 |
|---|---|
| 点検表ルートフォルダ(点検表フォルダ) | 点検表が入っている親フォルダ。中は カテゴリー > サブカテゴリー > ファイル の形 |
| カテゴリー | ルートフォルダの直下のフォルダ。上のタブになる(例: 梱包・押出・品質) |
| サブカテゴリー | カテゴリーの下のフォルダ。左の見出しになる(例: 日常点検・月次点検) |
| 命名規則 | ファイル名を「カテゴリー名_サブカテゴリー名_」で始める決まり。合わないものは一覧に出ない |
| 選択中 | 選んだ点検表の一覧。上から順に印刷する |
| 検出 / 更新 | 見つかった点検表の数 / 一覧を読んだ時刻(帯に出る) |
| 印刷範囲 | Excel の名前定義 `Print_Area`。プレビューの範囲もここから決める |
| 既定のプリンター | Windows のふだん使うプリンター。印刷先になる |
| 処理プログラム | `excel_worker.vbs`。cscript で動き、裏の Excel・Word を操作する |
| 再読込 | 点検表フォルダを読み直して一覧を新しくすること |
| 配布設定 | 1台の設定を `配布設定\` へ書き出し、ほかのラインのPCが起動時に読み込む仕組み |
| 管理者パスワード | 配布設定の操作とパスワード変更のときに入れる確認 |
| 問い合わせ番号 | 断り・失敗に付く番号。「月日-時分-4文字」(例: 1001-1502-7KQ2) |
| なぜなぜ | 問い合わせ番号から出す、現象 → なぜ1 → なぜ2 の表。その先は人が考える |
| 模擬モード | Excel を使わずに画面を確かめる起動の仕方(`--demo`) |
| デスクトップ版 / ブラウザ版 | 日報複合ツールの窓のタブで動く形 / `Start.vbs` でブラウザに出す予備の形。同時には動かない |
| 大設定 | 日報複合ツール全体の設定。点検表は「画面の色の既定」に従う |
