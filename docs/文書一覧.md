# 文書一覧

日報複合ツールと4つのツールの、仕様・操作説明・設計の考え方(思想)・モードの説明です。どの文書も同じ並び
(仕様 → 操作説明 → 思想 → モード説明 → 用語)で書いてあります。画面写真入りの操作説明書は、ツールの中の
「説明書」ボタン(F1)から開けます(`portal/static/manual/`)。

## ツールの説明

| 文書 | 中身 |
|---|---|
| [日報複合ツール.md](日報複合ツール.md) | 入口(1つの窓に4つのツールを大きなタブで並べたもの)。**必要なもの(Python・Flask・waitress などの一覧。同梱しない)**。デスクトップ版とブラウザ版、起動・終了・stop.bat、大設定(タブ表示権限・共有の置き場所・配布設定・画面の色・アクセス権限の早見表)、配布フォルダの作り方 |
| [日報管理ツール.md](日報管理ツール.md) | 日報の入力・保存(確定)・共有へ保存・印刷・集計・標準時間。直の決まり、保存を止める確かめ(7項目と休憩の時刻)、作業者・班長・管理者モード |
| [仕掛ファイルとカラム.md](仕掛ファイルとカラム.md) | 日報管理ツールが読む仕掛のファイル(SIKALOT・SIKAHIKI・SIKAODR・LS4LOT)と、どの列を何に使うか。第1パス・第2パスの置き場所と名前、手元へ写してから読む決まり、LS4LOT の名前で見る列が変わる決まり(BOX実績_作業開始_日付 の今の年月) |
| [GW計算.md](GW計算.md) | 日報管理ツールの GW計算(梱包資材重量)。入力・マスタ・8資材の計算式・計算の例・計算前の確かめ・オーダーからの自動選択・VBA と違うところ |
| [資材発注看板システム.md](資材発注看板システム.md) | 資材の発注看板。現場(発注・届いた確認)と倉庫(発送・注文中)、看板の色の意味、書き戻しと取り込み、マスタ管理(消せない看板・行き違いの知らせ)、印刷と看板集計 |
| [ライン管理カレンダー.md](ライン管理カレンダー.md) | ラインの休み・コメント・連絡のカレンダー。この端末と共有の同期、印刷、管理者パスワードで変えるもの |
| [点検表.md](点検表.md) | 点検表(Excel・Word)の選択・プレビュー・印刷。ラインごとの一覧の作り方、Excel・Word の動かし方、既に開いていたときの扱い |
