# ライン管理カレンダー(VER4.2.19)

月のカレンダーに、ラインの休み・コメント・連絡を登録して見るツールです。登録したものは共有フォルダを通して、ほかのラインのパソコンにも届きます。
Excel VBA + Access で動いていたツールを、Python + ブラウザの画面に置き換えたもので、いまは日報複合ツールの大きなタブ「カレンダー」として動きます。

- 出どころ: `tools/calendar/README.md`・`tools/calendar/docs/設計.md`・`tools/calendar/docs/デスクトップ版.md`・アプリ内の説明書 `portal/static/manual/calendar.html`・`portal/access_guide.py`
- 版の出どころは `tools/calendar/config/app.json` の `version` ただ 1 つです(画面の帯・印刷の右下・ログ・端末一覧が追随します)。

---

## 仕様

### 必要なもの

Python 3.9 以上と Flask(ブラウザ版で動かすときは waitress も)。配布フォルダには同梱せず、各 PC に入っているものを使います。一覧は [日報複合ツール.md](日報複合ツール.md) の「必要なもの」にあります。データの読み書きは標準ライブラリの sqlite3 だけです(ACE / ODBC は要りません)。

### 画面の一覧

左の並び(レール)で画面を切り替えます。

| 画面 | 何をするところか | だれが使うか |
|---|---|---|
| カレンダー | 月のカレンダー(7 列 × 6 行 = 42 マス)。日付を押して、休み・コメント/連絡の登録、内容閲覧、削除をします | だれでも(毎日) |
| 履歴 | 過去の月を**見るだけ**の画面。登録も削除もできません。「履歴・閲覧のみ」の札と紙のような茶色(セピア)の地が目じるしです | だれでも |
| 設定 | ライン・参照パス・取り込み・マスタ確認・管理などをまとめた画面。最初に 1 回、班長・管理者が決めます | 班長・管理者(見た目の設定はだれでも) |
| 印刷用の窓 | カレンダー・履歴の「印刷」で開く、A4 横 1 枚の印刷用の窓 | だれでも |

上の帯には、ツール名と版・この端末の「ライン」・「同期」の状態・暗くする/明るくする・今すぐ同期・終了 が出ます。

### 何を管理するか

管理するのは、日ごとの**休み**と**コメント・連絡**です(データ上はどちらも「休み管理」表の 1 行で、区分が `休み` / `その他`)。

| 登録するもの | 中身 |
|---|---|
| 休み | 休む作業者。A・B・C・D 班(3 交替)の人は、直(1直/2直/3直)・残業繋ぎ・早出繋ぎの担当者まで登録します。A〜D 以外の班(日勤など)は直を聞かずに登録します |
| コメント・連絡 | 班からの連絡の文。**どの班が残したか**(記入班)と**残した時刻**(登録日時)も一緒に残ります。連絡が出るのはそのラインの端末(と作業長の端末)です |

あわせて、次のものを持ちます。

| もの | 中身 |
|---|---|
| 班員名簿 | 作業者の一覧(管理番号・苗字・班・名前・読み・担当ライン)。マスタDB から取り込みます |
| 削除履歴 | 消した登録の記録(いつ・どの端末の誰が・何を消したか) |
| 端末一覧 | どの PC がどのライン・どの参照パス・どの版で動いているか(各端末の自己申告) |
| アクセス権限 | ログインID と PC名 で、その端末が使えるラインを決める表(梱包資材総合ツールと共用) |

カレンダーの色: 日曜・祝日は赤、土曜は青、今日のマスはオレンジの枠です。祝日には名前が出ます。休みのある日のマスにマウスを乗せると、残業繋ぎ・早出繋ぎの担当者が小さな札で出ます。連絡のある日は、同じ札に「L-1 B班からの連絡　2026/10/21 14:05」のように**どの班からか・いつ残したか**が出ます。

**ラインによる表示の絞り込み**(この端末のラインで、出るものが変わります。**マス目・マウスを乗せたとき・内容閲覧・
削除の選択肢・印刷はみな同じ決まり**です。VER4.2.6)

| この端末のライン | 休みの表示 | コメントの表示 |
|---|---|---|
| 作業長 | 全ライン | 全ライン |
| コイル | コイルのみ | コイルあてのみ |
| その他のライン | コイル以外すべて | 自分のラインあてのみ |

選べるライン名は `コイル・LVC・HVC・機側・L-1・AIM・NS1・大板小板・作業長` です(`calendar_app/config.py`)。

### データの置き場所

**正式なデータは、共有フォルダに置いた「取り込み元」(`.sqlite3`)だけ**です。各 PC の手元の SQLite は「表示用の写し」と「まだ送れていない入力の置き場(送信待ち)」にすぎません。

| 置き場所 | ファイル | 中身 | 注意 |
|---|---|---|---|
| この端末だけ(`%LOCALAPPDATA%\LineCalendar\`) | `data\settings.json` | この端末の設定(ライン・参照パス・自動同期・管理者パスワードの撹拌した値・ログフォルダ・画面の見た目) | 消すと初めの状態に戻る |
| | `data\calendar.db` | 共有の写しと、**まだ送れていない入力** | **消さない**(送信待ちが届かなくなる) |
| | `backup\` `logs\` | 控え・ログ | 消してもアプリは動く |
| | `runtime\` `cache\` `work\` `pycache\` | 実行中の情報・一時ファイル | 止めているときなら消してよい |
| 全端末で共有(参照パスの先) | `連絡帳.sqlite3` | 休み管理・削除履歴・端末一覧 | 全端末の正式なデータ |
| | `梱包資材マスタ.sqlite3` | 班員名簿・アクセス権限(梱包資材総合ツールと共用) | マスタ管理から直す |
| アプリのフォルダ | `配布設定\` | 配る前に書き出した設定 | 配った先が起動時に読む |
| | `config\app.json` | 版番号など | 新しい版で差し替わる |

> 日報複合ツールでは、大設定の「4ツールの分もまとめて書き出す」で、このツールの配布設定が大設定の `配布設定\日報複合ツール.json` にも入ります(この1つのファイルだけでも届きます)。このツールのフォルダの配布設定と両方あるときは、**作った時刻が新しいほう**を丸ごと使います(同じならこのツールのフォルダのほう)。中身は大設定の「配布設定」の「各ツールの配布設定(中身)」で確かめられます(詳しくは `docs/日報複合ツール.md` の「配布設定」)。

- 「この端末だけ」のファイルは、**Windows の利用者ごと・PC ごとに別**です。同じ PC でも別の人がログインすると別になります。
- アプリのフォルダには、実行中に何も書きません。アプリのフォルダは共有に置いてもかまいません。
- 参照パスは**ファイルではなくフォルダ**で持ちます。保存用DB のフォルダ(連絡帳)とマスタDB のフォルダ(班員名簿)の 2 つで、マスタDB が空欄なら保存用と同じ場所を見ます。
- 設定画面の「7. ファイルの置き場所」に、この端末での実際の場所が出ます。

### 同期の仕組み

```
入力 → この端末の SQLite に保存(すぐ画面に出る)
         ↓ 直後に自動で
       取り込み元(共有)へ送る(送れたら送信待ちから消す)
         ↓ 決まった間隔(既定 20 秒)で
       取り込み元から取り込み直す(ほかのラインの登録が見える)
```

- 取り込みの間隔は設定で変えられます(最短 5 秒)。ほかのラインの登録は、最大でこの間隔ぶん遅れて見えます。
- 班員名簿も、自動同期のたびにマスタDB から入れ直します。
- 送れなかったとき(共有フォルダに届かない・ロック競合など)は、入力は送信待ちに残り、次の機会に送り直します。**入力が失われることはありません。**
- 未送信の入力があるあいだは取り込みをしません(取り込みは表を入れ替えるので、送れていない入力が消えるため)。
- 同じ日に同じ人の休みを、別のラインが先に登録していたときは、こちらの登録は送らず、画面に「送らなかった登録があります」と知らせます。
- 開いたままでも、取り込みのたびと日付が変わったときに、画面は自動で描き直されます。窓(内容閲覧など)を開いているあいだは待ち、閉じたあとで新しくなります。
- 参照パスが決まっていない(「参照パスが未設定」)ときは、休み・連絡の登録と削除はできません。閲覧・印刷はいつでもできます。
- 終わるときは、送れていない入力があれば送ってから閉じます。送れないまま閉じても登録は消えず、次に開いたときに送られます。

上の帯の「同期」の表示:

| 表示 | 意味 | すること |
|---|---|---|
| 同期済み(日時) | 送り終わっていて、その時刻の内容を見ている | 何もしなくてよい |
| 送信待ち ○ 件 | 送っている途中 | 少し待つ |
| 未送信 ○ 件 / (理由) | 共有フォルダに届かず送れていない。入力はこの端末に残っている | そのまま使ってよい。長く続くときは班長・管理者へ |
| 参照パスが未設定 | 参照パスが決まっていない。登録もできない | 管理者に設定を頼む |

### 出力・印刷

- カレンダー・履歴のどちらにも「印刷」があり、その月を **A4 横 1 枚**で刷ります。
- 印刷用の窓が開き、「印刷する」で印刷の画面、「閉じる」でその窓だけ閉じます。ボタンと案内の文は紙には刷られません。
- 右下に、出力日時・ライン・版が刷られます。
- 文字・罫線・色帯は、紙の端から 8mm 内側に描きます(プリンターは紙の縁から約 4mm に刷れないため)。点線の内側だけが刷られ、点線は刷られません。
- 登録が多い月は、自動で縮めて 1 枚に収めます(切り捨てません)。余白は「既定」のまま、倍率は変えないで刷ります。
- 曜日の見出しや土日祝の色は、「背景のグラフィック」を入れなくても刷られます。画面の見た目(ダーク)に関係なく、いつも白い紙の色で刷ります。
- PDF にしたいときは、プリンターに「PDF に保存」を選びます。
- このほか、設定 → 9. ログ で、記録番号から「なぜなぜ分析の材料」を 1 枚にまとめ、写す・テキストファイルに保存することができます(管理者・問い合わせのとき)。

## 操作説明

開きかた: 日報複合ツールの大きなタブの「カレンダー」を押します。少し待つとカレンダーの画面が出ます。月は「← 前月」「当月」「翌月 →」(キーボードの PageUp / PageDown でも)で切り替えます。

### 日付を押す(すべての操作の入口)

1. カレンダーの日付のマスを押します。
2. 「○月○日 の操作を選んでください」が出ます。**休み**・**コメント・連絡**・**内容閲覧**・**削除** から選びます。
3. やめるときは「取り消し」を押します。

### 休みを登録する

1. 日付を押して「休み」を押します。
2. 「休みにする作業者」の一覧から、休む人の名前を押します(班ごとに縦に並んでいます)。
3. A・B・C・D 班の人なら「○○ さんの直」が出ます。1直・2直・3直 から休む直を押します。A〜D 以外の班の人は、直は聞かれず、ここで登録されます。
4. 「○直の残業で繋ぐ人」(見出しがオレンジ、札は「残業繋ぎ」)が出ます。休んだ直の**前の直**で残業して繋ぐ人を押します。
5. 「○直の早出で繋ぐ人」(見出しが青緑、札は「早出繋ぎ」)が出ます。休んだ直の**次の直**で早出して繋ぐ人を押します。上に出る「ここまでに選んだもの」で、休む人・直・残業繋ぎ が正しいか確かめます。
6. 繋ぐ人がまだ決まっていないときは「未登録のまま」を押します(「未登録」として登録されます)。
7. 右下に「○○ さんの休みを登録しました」と出て、マスに「コイル:B班:作業者05 休」のように出れば終わりです。

同じ日に同じ人をもう一度登録しようとすると「既に登録済みです」と出て、登録されません。直や繋ぎを直したいときは、先に削除してから登録し直します。

### コメント・連絡を登録する

1. 日付を押して「コメント・連絡」を押します。
2. 「連絡を残す班」で、**自分の班**を選び、「次へ」を押します。ラインはこの端末のラインが選ばれていて、変えられません(ほかのラインへの連絡は、そのラインの端末にしか出ないためです)。**作業長の端末だけ**はラインも選べます(ラインを選ぶと、班はそのラインにある班だけになります)。
3. 「○○ ○班からの連絡」の窓で連絡の文を入力して「登録する」を押します。
4. 「○○ ○班からの連絡を登録しました」と出て、マスに「コイル:B班 コメント有」のように出れば終わりです。文と残した時刻を読むときは「内容閲覧」を使います(マスにマウスを乗せても、どの班からか・いつ残したかが出ます)。

VER4.2.3 までに登録した連絡は、どの班が残したかと時刻が記録されていません。そのため「コイル:(班なし) コメント有」「コイル 連絡(班なし)　時刻の記録なし」と出ます(そのころ選んでいた班は**宛先**の班なので、「からの連絡」とは出しません)。

### 内容を見る(内容閲覧)

1. 日付を押して「内容閲覧」を押します。
2. その日の登録のうち、**この端末のマス目に出るもの**が出ます(休みは直と繋ぎの担当者まで、連絡は「コイル B班からの連絡　2026/10/21 14:05」のように、どの班から・いつ残したかと文まで)。読むだけなので、ここで消えたり変わったりしません。
3. 「閉じる」で戻ります。

### まちがえた登録を消す(削除)

1. 日付を押して「削除」を押します。
2. その日の登録のうち、この端末のマス目に出るものが並びます。消したいものだけにチェックを入れて「選んだものを削除」を押します。
   ほかのラインの登録は、作業長の端末か、そのラインの端末で消します(この端末からは消せません)。
3. 「削除の確認」が出ます。よければ「削除する」、やめるときは「やめる」を押します。
4. 「1 件を削除しました」と出れば終わりです。

消した登録はカレンダーからは戻せません。消した内容は削除履歴に残ります。

### 印刷する

1. 印刷したい月を出して、右上の「印刷」を押します。
2. 印刷用の窓で「印刷する」を押し(Ctrl+P でも同じ)、プリンターを選んで印刷します。
3. 終わったら「閉じる」を押します。

### ほかのラインの登録をすぐ見る(今すぐ同期)

1. 上の帯の「今すぐ同期」を押します。
2. 右下に「同期しました」と出て、カレンダーが新しくなります。届かないときは「送れませんでした: …」と出ます。

### 過去の月を見る(履歴)

1. 左の並びの「履歴」を押します。
2. 「年月を選ぶ」を押すと、年ごとに 12 か月のマスが出ます(マスにはその月の登録件数)。「← 前の年」「次の年 →」で年を変えて、見たい月を押します。
3. 日付を押すと、その日の登録内容が出ます(読むだけ)。
4. 「← 前月」「翌月 →」でとなりの月へ、「印刷」でその月を印刷します。

選べるのは、登録がある一番古い月から先月までです(点線のマスは選べません)。今月から先は「カレンダー」で見ます。

### 最初の設定(班長・管理者)

1. 左の並びの「設定」を開きます。
2. 「1. この端末のライン」でラインを選び、保存します(管理者パスワードが要ります)。
3. 「2. 参照パス」で取り込み元(共有フォルダ)の場所と、自動同期の「する/しない」・取り込み間隔(秒)を決めます(場所を変えるには管理者パスワードが要ります)。
4. 「3. 取り込む」で「参照パスから取り込む」を押し、班員名簿の人数が出ることを確かめます。

ラインをまちがえると、何も起きていないように見えたまま表示だけがずれます。管理者パスワードを知っていても、ラインは勝手に変えないでください。

### 終わる

1. 日報複合ツールの右上の「終了」を押して閉じます。
2. カレンダーの帯の「終了」でも閉じられます。「終了しますか?」で「終了する」を押すと、日報複合ツール全体(ほかのツールのタブも)が閉じます。

### 困ったとき(主なもの)

| こうなった | こうする |
|---|---|
| 「班員名簿が取り込まれていません」と出る | 設定の「3. 取り込む」で「参照パスから取り込む」を押す。「参照パスが未設定」なら管理者に頼む |
| 休みを押すと「作業者が居ません」と出る | 班長・管理者に、設定の「取り込む」と「この端末のライン」を見てもらう |
| 帯に「未送信 ○ 件」、設定に「!」が出る | 入力は残っている。少しして「今すぐ同期」を押す。長く続くときは班長・管理者へ |
| 「送らなかった登録があります」と出る | ほかのパソコンが先に同じ人・同じ日を登録していた。その日の登録を確かめ、違うときは削除してから登録し直す |
| ほかのラインの登録が出てこない | 「今すぐ同期」を押す。それでも出ないときは帯の「ライン」が正しいか確かめる |
| 「すでに別の画面で開いています」と出る | 同じパソコンでもう 1 つ画面が開いている。こちらで使うなら「この画面で使う」を押す |
| 「思わぬエラーが起きました(記録番号 E…)」と出る | もう一度やる。だめなら記録番号をメモして管理者に伝える |
| 「バックエンドに接続できません」の帯が出る | 「再接続」→「再読込」→ 日報複合ツールを終了して開き直す |

## 思想(設計の考え方)

ソースに書かれている考え方を、短くまとめます。

| 考え方 | ソースの言い方と中身 |
|---|---|
| 正式なデータは 1 か所 | 「正式なデータは共有の取り込み元(`.sqlite3`)だけ」。手元の SQLite は表示用の写しと送信待ちの置き場にすぎません |
| 入力を失わない | 送れなくても送信待ちに残し、「入力が失われることはありません」。未送信を抱えたままは終わらず、送ってから閉じます |
| 「保存できたつもり」を作らない | 「『保存できたつもり』が一番たちが悪い」。参照パスが決まっていなければ、入り口で登録を断ります |
| 古いものを最新だと読ませない | 朝に開いて一日中そのまま使う前提で作り、取り込み・日付の変わり目で自動で描き直します |
| 気づけないずれを防ぐ | ライン設定のまちがいは「何も起きていないように見えたまま表示だけがずれます」。だから管理者パスワードの関門と、端末一覧を置きました |
| 毎日使うものと最初に 1 度決めるものを分ける | 日付を押す操作と、ライン・参照パスの設定を別の画面に分けました。関門を置いても現場の手数は増えません |
| 過去は見るだけ | 履歴は「書き込む道を持たない」。押しまちがいで昔の記録が変わらないようにします |
| 記録は直せない | 削除履歴は「直せる記録は記録になりません」。端末一覧の「ライン」も実績なので直せません(直すかわりに「次のライン」で予約します) |
| 消しすぎない・上書きしない | 削除の転送で消すのは必ず 1 行だけ。マスタを 2 人が同時に直したら、後の人を断って最新を見せます |
| 色だけで意味を運ばない | 残業繋ぎ・早出繋ぎは色に加えて、札の文字・見出し・段数・「ここまでに選んだもの」で区別します |
| 一覧に無いものは選べない | 画面で絞るだけでなく、サーバでも確かめます |
| 業務判断はすべて Python | 画面(JS)はサーバが返した内容を写すだけ。「同じ事実を 2 か所に持たない」 |
| 事実だけを残す | エラーには記録番号を出し、ログから「なぜなぜ分析」の事実の欄を埋めます。「原因の推測は書きません」 |

### 保守する人へ(VBA → Python の移し方)

- 業務判断は VBA の移植です。判定の条件は変えずに移しています(例: 祝日判定 `modHoliday` → `calendar_app/holiday.py`、`modData`/`modDB` → `calendar_app/repository.py`、レジストリ → `settings.json`、Excel 印刷 → HTML 印刷)。対応表は `tools/calendar/README.md` の 5 章にあります。
- Access をやめて SQLite にした一番の理由は、Access のころは書き込み経路を試験できず、壊れても気づくのが現場で、しかも症状が「保存できたつもり」だったことです。
- 共有フォルダ上の SQLite は壊れ方が「破損」になりうるため、**WAL にしない(`journal_mode=DELETE`)・`busy_timeout` を置く・書き込みは短いトランザクション・書く前に控えを取る** の 4 点を守ります。取り込み元を WAL にしないでください。
- VBA のロック再試行(`IsLockError`・最大 3 回)は、取り込み元へ書く側に同じ基準で移してあります。
- `calendar_app/dbkit/` は、このアプリを知らずに動く部品で、ほかの VBA → Python 移行でもそのまま使えます。表名 `Access同期記録` は、名前を変えると送信記録が読めず全件再送になるため、そのままにしています。
- 試験は `python -m unittest discover -s tests -t .` で流します(`-t .` を付けると、試験の保存先が一時フォルダに逃げます)。

## モード説明

このツールには「モード」という名前の切り替えはありません。ソースが決めているのは、**だれが何を変えられるか**(管理者パスワード・アクセス権限)と、**画面ごとの扱い**(履歴は閲覧のみ・参照パスが無いと登録できない)です。日報・看板の `Administrator`・`mode:fullaccess`・`mode:field`・`mode:material` は、このツールでは**読みません**(`portal/access_guide.py`)。

### 使う人・画面による違い

| 名前 | なれる人・なり方 | できること | できないこと |
|---|---|---|---|
| ふつうの利用 | だれでも。カレンダーのタブを開くだけ | 休み・コメント/連絡の登録、内容閲覧、削除、印刷、履歴を見る、今すぐ同期、画面の見た目の切り替え、「3. 取り込む」 | ライン・参照パスの変更、配布設定、アクセス権限・ライン予約の変更 |
| 管理者(管理者パスワードを知っている人) | 設定で、守られた値を変えるときにパスワードを入れる(聞かれるのは本当に値が変わるときだけ) | この端末のライン・参照パス(保存用DB/マスタDB のフォルダ)の変更、管理者パスワードの変更、配布設定の書き出し・読み込み直し・消す、アクセス権限の行を足す・直す・消す、端末一覧の「次のライン」(予約) | アクセス権限の表に無いラインを選ぶこと(パスワードでも通らない)、端末一覧の「ライン」や削除履歴を直すこと |
| 履歴(閲覧のみ) | 左の並びの「履歴」を押す | 過去の月を見る、日の登録内容を読む、印刷 | 登録・削除(ボタンも書き込む道もない)、今月から先を見る |
| 参照パスが未設定 | 参照パスが決まっていない端末は自動でこの状態 | 閲覧・印刷 | 休み・連絡の登録と削除 |

- 管理者パスワードは、ソースのことばで「アクセス制御ではありません」。誤って押されないためのガードで、知っている人ならだれでも変えられます。初期値があるので、**配る前に変えて、「6. 配布設定」で書き出します**。
- パスワードを忘れたときは、`settings.json` の `管理者パスワード` の行を消すと既定に戻ります(配布設定があるツールでは、次の起動で配布設定のパスワードが入ります)。
- 違うパスワードは 3 回で打ち切り、戻し方を案内します。

### アクセス権限(この端末で使えるライン)

梱包資材マスタの「アクセス権限」表で、ログインID と PC名 から、その端末が使えるラインを決めます。設定 → 4. マスタ確認・管理 → 表で「アクセス権限」を選んで行を足します(管理者パスワードが要ります)。

| この端末(ログインID・PC名)に当たる行 | なり方 | できること | できないこと |
|---|---|---|---|
| 1 行 | 表にライン名を 1 つ書いた行がある | そのラインに固定して使う | 画面でラインを選ぶこと |
| 複数行 | 当たる行が 2 つ以上ある | そのラインの中で選ぶ(切り替えは管理者パスワード) | 表に無いラインを選ぶこと |
| 無い(表が無い・登録していない) | 何も書かない | 管理者パスワードで、どのラインにも切り替えられる | (特になし。登録前に全員が締め出されないため) |

権限の欄の読み方(カレンダー):

- 権限にはライン名を **1 行に 1 つだけ**書きます。並べて書いた欄や、字の違う書き方(`ｺｲﾙ` など)は読みません。
- 空欄は「問わない」。ただし、ログインID も PC名 も空の行は、だれにも効きません(全員への許可になるため)。
- 「有効」が 0・false・off・no・×・無効(大文字小文字は問わない)の行は読みません。看板・日報と同じ読み方です(VER4.2.2 から。前はカレンダーだけ FALSE・off・× を有効と読んでいました)。ログインID・PC名 の大文字小文字は問いません。
- `mode:field` など、ほかのツールの値は読まずに、そのまま残します。
- いまのラインが表に無ければ、起動したときと、同期で表を取り込み直したときに、表のラインへ合わせます。端末一覧の「次のライン」より表が優先です。

## 用語

| 用語 | 意味 |
|---|---|
| 取り込み元 | 共有フォルダに置いた正式なデータ(`連絡帳.sqlite3`・`梱包資材マスタ.sqlite3`) |
| 参照パス | 取り込み元がある**フォルダ**の場所。保存用DB のフォルダとマスタDB のフォルダの 2 つ |
| 保存用DB(連絡帳) | 休み管理・削除履歴・端末一覧が入る `連絡帳.sqlite3` |
| マスタDB | 班員名簿・アクセス権限が入る `梱包資材マスタ.sqlite3`(梱包資材総合ツールと共用) |
| 手元の SQLite | 各端末の `calendar.db`。表示用の写しと送信待ちの置き場 |
| 送信待ち | まだ取り込み元へ送れていない入力。送れたら消える |
| 自動同期 | 送る・取り込むを決まった間隔(既定 20 秒)で自動で行うこと |
| 今すぐ同期 | 帯のボタン。ほかのラインの登録をすぐ取り込む |
| 直 | 3 交替の 1直・2直・3直。A・B・C・D 班の人だけ聞かれる |
| 残業繋ぎ | 休んだ直の前の直で、残業して繋ぐ人 |
| 早出繋ぎ | 休んだ直の次の直で、早出して繋ぐ人 |
| 未登録 | 繋ぐ人がまだ決まっていないときに選ぶ値 |
| コメント有 | 連絡が登録された日のマスに出る印。「コイル:B班」はB班が残した連絡。文は内容閲覧で読む |
| (班なし) | VER4.2.3 までに登録した連絡に出る札。どの班が残したかが記録されていない |
| 内容閲覧 | その日の登録をすべて読む操作(読むだけ) |
| 削除履歴 | 消した登録の記録。直せない |
| 班員名簿 | 作業者の一覧。マスタDB から取り込む。設定の「マスタ確認・管理」で確認・修正できる |
| 端末一覧 | どの PC がどのライン・参照パス・版かの一覧(各端末の自己申告) |
| 次のライン(ライン予約) | 端末一覧に入れておくと、その端末が次に起動したときに受け取るライン |
| アクセス権限 | ログインID と PC名 で、端末が使えるラインを決める表 |
| 作業長 | 全ラインの休み・コメントを見られるライン設定 |
| 管理者パスワード | ライン・参照パスなどを変えるときの関門。アクセス制御ではない |
| 配布設定 | 1 台で決めた設定を書き出して、配った先で起動時に読み込ませるしくみ(ラインは既定で入れない) |
| 履歴 | 過去の月を見るだけの画面 |
| 記録番号 | 思わぬエラーのときに出る番号(`E` + 日時 + 3 文字)。管理者に伝える |
| なぜなぜ分析の材料 | 記録番号からログの事実を 1 枚にまとめたもの(設定 → 9. ログ) |
| 大設定 | 日報複合ツールの設定のタブ。アクセス権限の早見表や、4 ツールの配布設定のまとめ書き出しがある |
| ブラウザ版(予備) | `Start.vbs` で既定のブラウザに開く版。日報複合ツールが開けないときに管理者が使う |
