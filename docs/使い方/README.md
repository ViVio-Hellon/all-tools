# 使い方(現場向けの文書の置き場所)

画面を使う人のための文書をここに置きます。仕様や設計の文書は一つ上の [文書一覧](../文書一覧.md) です。

## すぐ開く

| 文書 | 中身 |
|---|---|
| [日報入力テクニック集](日報入力テクニック集.md) | 日報入力で打つ回数を減らす近道(ダブルクリック・Enter・行の番号から順に打つ・時間を割り振る・LOTで時間を割り振る ほか) |
| 操作説明書(画面写真入り) | ツールの中の「説明書」ボタン(F1)。ファイルは `portal/static/manual/`(日報 `nippou.html`・看板 `kanban.html`・カレンダー `calendar.html`・点検表 `inspection.html`・入口と大設定 `portal.html`) |

## 文書を足すとき

- 現場の人が読む「やり方」はこのフォルダへ(名前は `○○集.md`・`○○の手順.md` のように中身が分かるもの)。
- 足したら、この表と [文書一覧](../文書一覧.md)・リポジトリの一番上の README の「文書」の行にも載せます。
