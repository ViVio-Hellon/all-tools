# 日報入力テクニック集(日報管理ツール VER4.44.5)

日報入力で**打つ回数を減らす近道**を、場面ごとにまとめました。どれも**押した・欄を離れたときだけ**値が入ります
(打っていない値が黙って入ることはありません。入った欄は一瞬光ります)。欄や列の見出しにマウスを乗せて少し待つと、
短い説明が出ます。

> 画面写真入りの説明は、ツールの中の「説明書」(F1)→ 日報管理ツール の「4-2. 行を打つ」「打つときのこつ」。
> 仕様と決まりは [日報管理ツール.md](../日報管理ツール.md)。

## 早見表

| やりたいこと | どうする | 入るもの |
|---|---|---|
| 行をまとめて埋める | **ロット№を7桁**打つ | 材・調質・製品寸法・検入枚数・合紙・ＶＣ種別・単重(etc の「外注」「EX」も付くことがある) |
| 次の欄へ | **Enter**(戻るは **Shift+Enter**) | 2桁で自動で進むのと同じ順。行の最後の次は次の行のロット№ |
| いまの時刻を入れる | 開始・終了の「時」か「分」を**ダブルクリック** | いまの時刻を時と分の2欄へ(分の1の位は 0 か 5 に寄せる) |
| 直の終わりの時刻を入れる | 終了の欄に入ると下に出る **「直の終わり 15:00」** を押す | 開いている直の終わりの時刻(丸めない) |
| 上の行と同じ数 | 個装単位 枚数か包数を**ダブルクリック** | 上の行(いちばん近い、枚数の入った行)の枚数と包数 |
| 包数を打たない | 包数を**空のまま**欄を離れる | 1 |
| 1行を Enter だけで打つ | **行の番号をダブルクリック** | 作業開始 → 作業終了 → 作業人数 → 合紙 → 枚数 → 包数 の順に聞く窓 |
| 時刻を打たずに埋める | **時間を割り振る** / **LOTで時間を割り振る** | 下の「時間を割り振る」 |
| etc を入れる | 表の上の **ｽﾄｱ・耳付・外注・EX・反転・ｽﾎﾟｯﾄ・同梱なし** | いま打っている行の etc に付く(もう一度押すと消える) |
| 作業者を班ごと選ぶ | 作業者を選ぶ窓で**班の名前**を押す | 班の全員にチェック(もう一度で全員外れる) |

## 1. ロット№を打つ

- **7桁そろうと、その行が自動で埋まります**(材・調質・製品寸法・検入枚数・合紙・ＶＣ種別・単重)。違っていれば打ち直せます。
- 1つのロットに引当が2つ以上あると「引当を選ぶ」の窓が出ます。正しい引当を選んで「この引当で埋める」。
- **前の直から続くロット**なら「1直で15枚作業しています。検入数を変えますか?(20枚 → 5枚)」と訊きます。OK で検入枚数が
  残りの枚数に、キャンセルなら仕掛ロットの枚数のまま。
- 同じロットを分けて打つ**続きの行はロット№を打ちません**(空の行は上の行と同じロットとして数えます)。

## 2. 欄を進む

- **2桁(時・分)・1桁(作業人数)を打つと、次の欄へ自動で進みます。** Enter でも進みます(Shift+Enter で戻る)。
- 2桁で自動で進んだ直後(0.8秒以内)の Enter は1回だけ見送ります(押し癖で1つ飛ばさないため)。
- **停止**: 時間(分)を3桁打つと次の組へ進みます。記号を空のまま Enter を押すと、残りの組は飛ばします。
- 停止の記号の一覧のいちばん上に**「よく使う(このライン)」**が出ます(最近の60ページで多い順に7つまで)。

## 3. 時刻を入れる

| 近道 | 動き |
|---|---|
| 開始・終了の「時」か「分」を**ダブルクリック** | いまの時刻を2欄へ。分の1の位は 1〜4 切り捨て・5 そのまま・6〜9 切り上げ(13:03 → 13:00、13:07 → 13:10) |
| **「直の終わり」** | 終了の欄に入ると、すぐ下に「直の終わり 15:00」が出ます。押すと開いている直の終わりの時刻。次の行の開始には写りません |
| 終了を打つ | 次の行の開始に同じ時刻が入ります |
| 次ページ発行 | 2ページ目の1行目の開始に、前のページの最後の行の終了が入ります(直の終わりで終わっていたときは入りません) |

- 過去の直を開いているあいだは、ダブルクリックでいまの時刻は入りません(その直の時刻ではないので)。「直の終わり」は入ります。

## 4. 数を入れる

- **個装単位 枚数か包数をダブルクリック** → 上の行と同じ枚数・包数(停止だけの行は飛ばしてさかのぼる)。
- **包数は空のまま離れると 1**(実物の日報はすべて 1 でした)。
- 実績合計の枚数(枚数 × 包数)・重量(枚数 × 単重)は自動で出ます。枚数や包数を直して「◯行目の重量を ◯◯ に変更しますか？」と
  聞かれたら、ふつうは OK(量った重量を残したいときだけキャンセル)。

## 5. 行の番号をダブルクリック ── Enter だけで1行を打つ

行の番号をダブルクリックすると、その行のすぐ下に聞く窓が出ます。**打って Enter** で表へ入れて次の欄へ。

    作業開始 0815 Enter → 作業終了 0911 Enter → 作業人数 3 Enter → 合紙 → 個装単位 枚数 → 梱包単位 包数

- 時刻は4桁(0815)。3桁(815)・8:15 でも入ります。合紙は 1 = 有・2 = 無・0 = 空。
- 空のまま Enter は今の値のまま。Shift+Enter で前へ、Esc でやめる(入れたぶんは残る)。打ち終えたら次の行のロット№へ。

## 6. 時間を割り振る ── 時刻を打たずに埋める

設定・管理者の「時間を割り振る」をオンにした端末だけ、ボタンが出ます。どちらも**押す前に確かめの窓**が出ます。

| ボタン | 割り振る行 | 時間 |
|---|---|---|
| **時間を割り振る** | この直の打った行すべて(全ページ) | 直の開始 〜 直の終了 |
| **LOTで時間を割り振る** | 選んでいる行のロットの行だけ(選んでいなければ直の最後のロット) | 始まり: 1ロット目は直の開始、2ロット目からは前のロットの最後の行の終了 / 終わり: そのロットの最後の行の終了、無ければ押した時刻(最後のロット)か次のロットの始まり |

**LOTで時間を割り振るの使い方**

1. ロットを打ち終えたところで押す(終わりは押した時刻。ダブルクリックと同じく5分に寄せる)
2. 押し忘れたら: そのロットの最後の行の終了をダブルクリックで入れておけば、あとで押してもその時刻まで
3. 前のロットをやり直す: そのロットの行を選んで(欄を押して)から押す。ほかのロットは触りません

**どちらも同じ割り振り方**

- 停止の分はその行に先に渡し、残りを**梱包数(枚数 × 包数)の比**で分けます(梱包数が無ければ等しく)。
- **EX のロット**の行は長め、**ロットの変わり目の1梱包目**は段取りのぶん長め、前のロットと **VC が違えば** VC交換のぶんも長め
  (倍率は設定・管理者で変えられます。既定 EX 1.2倍・段取り 1.5倍・VC交換 1.5倍)。
- **段取り(板)**の停止がある行は段取りのぶんを、**VC交換(板)**の停止がある行は VC交換のぶんを足しません(段取り変更では変えません)。
- **休憩**(1直 12:00〜13:00・2直 18:00〜19:00・3直 02:00〜03:00)にかかる行は60分のばし(行はつながったまま)、その行に休憩「0」60分を入れます(昼稼働「有」の直はのばしません)。
- 区切りは時計の**5分刻み**。

## 7. 停止・休憩

- **0 休憩食事**を選ぶと「休憩の時刻」の窓。先に①休憩の分(60)、次に②何時から何時まで(`11:30〜12:30`、`1130-1230` でも可)。
  1行に2つあるときは `10:00〜10:10、12:00〜12:50` と「、」で並べます。
- **ヨ その他(理由を記載)**を選ぶと「理由を書く」の窓。
- 直のあいだ設備がずっと止まっていたときは **全停入力**(直に1回だけ)。
- 停止は表に1組ずつ出ます。見出しの ①〜⑤ で組を替えます。右の「停止」の欄に、どの組に入っているかと合計の分。

## 8. そのほか

- **行を空にする**: 行の番号の横の ✕ → 「空にする」。
- **12行を使い切ったら**「次ページ発行」(いまのページを保存して2ページ目へ)。
- **作業者を班で選ぶ**: 窓で班の名前を押すと班の全員にチェック。手で打った名前や「新人教育」などの書き添えは、選び直しても残ります。
