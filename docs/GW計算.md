# GW計算(梱包資材重量計算) ── 日報管理ツール VER4.38.0

日報管理ツールの「GW計算」タブです。ロット番号から製品の寸法と受注を引き、梱包の形(枚数・バンド・梱包高さ・
パレット)を入れると、梱包資材ごとの重量、風袋総重量、GW(総重量)を出します。VBA の `UFGW` / `NewGW` /
`GetUnitMassAndCoefficient` を移したもので、計算式は `tools/nippou/nippou/logic/gw_calculation.py` の1か所にあります
(画面・内訳・印刷はすべてそこを呼びます)。

## 仕様

### 入力

| 囲み | 欄 | 単位 | 出どころ |
|---|---|---|---|
| 製品情報 | LotNo | ― | 人が打つ(7桁) |
| 製品情報 | オーダーNo | ― | ロットから決まる(引当が複数なら選ぶ) |
| 製品の寸法 | 板厚 / 板幅 / 板丈 | mm | SIKALOT の製造板厚・板幅・板丈(打ち直せる) |
| 梱包の形 | 梱包締枚数 | 枚 | 人が打つ |
| 梱包の形 | 縦バンド本数 | 本(0〜2) | 人が打つ。輸出形態で自動のこともある |
| 梱包の形 | 横バンド本数 | 本(2本以上) | 人が打つ |
| 梱包の形 | 梱包高さ(パレット含) | mm | 人が打つ |
| 梱包の形 | パレット+蓋の重量 | kg | 人が打つ |
| 梱包の形 | 積み形態 | 1山 / 2山 / 3山 | 人が選ぶ(列 = 山の数) |
| 使う資材 | ダンプレート・外装紙・合紙・バンド・ポリシート・縦バンドアングル・ハードボード | チェック | 合紙・縦バンドアングルは受注から自動。ほかは最初から付いている |
| バンド種別 | シール無 / シール有 / PETバンド | ― | 取引先・納入先・包装仕様NOで自動(変えられる) |
| VCフィルム | 使用・A面・B面・品名 | ― | 受注の VC_表 / VC_裏 から自動 |
| 積合せ | 有り・重量 | kg | 人が打つ |
| Aインプット重量 | 製品の重量 | kg | 人が打つ(空ならGWは出さない) |

### マスタ

| ファイル | 表 | 使う列 | 何に使うか |
|---|---|---|---|
| 梱包資材マスタ.sqlite3 | 資材重量 | 梱包資材名・単位質量・係数 | 7資材の単位質量と係数 |
| 梱包資材マスタ.sqlite3 | VC重量 | 品名・単位質量・係数 | VCフィルムの単位質量と係数 |
| SIKALOT / SIKAHIKI / SIKAODR | 仕掛 | 寸法・受注番号・VC・合紙・包装仕様NO・取引先・納入先 | 寸法と自動選択 |

資材重量で引く名前: ダンプレート / 外装紙 / 合紙 / ポリシート / 縦バンドアングル / ハードボード、バンドは
「帯鉄シール無」「帯鉄シール有」「PETバンド」(選んだ種別で1つ)。名前は完全一致で引きます。

### 計算式

記号: 板厚 t、板幅 W、板丈 L、枚数 N(梱包締枚数)、列 n(1山=1・2山=2・3山=3)、
積み枚数 = 切り上げ(N ÷ n)、**山の高さ H = t × 積み枚数**、梱包高さ K(パレット含)。
mm² → m² は ÷10⁶、mm → m は ÷10³。

**重量(kg) = 基準量 × 単位質量 × 係数**(8資材すべて同じ。VCフィルムも係数を掛ける)

| 資材 | 基準量 | 単位 | 意味 |
|---|---|---|---|
| ダンプレート | (W×n + L) × 2 × H ÷ 10⁶ | m² | 製品の側面ぐるり |
| 外装紙 | {(W×n + L) × 2 × H + W×n × L × 2} ÷ 10⁶ | m² | 側面ぐるり + 上下 |
| ポリシート | {(W' + L') × 2 × H' + W' × L'} ÷ 10⁶<br>W' = W×n + 200、L' = L + 200、H' = H + 200 | m² | 側面ぐるり + 天面。各寸法 +200mm(大きめに包む) |
| 合紙 | W × L × (N + 1) ÷ 10⁶ | m² | 板と板のあいだ + 上下で、枚数より1枚多い。2山・3山でも +1 |
| バンド | {縦 + 横} ÷ 10³ | m | 下の2行の合計 |
| 　縦バンド | (L + H + ハードボード 5mm × 2 + 蓋・桟 40mm) × 2 × 縦本数 | mm | 蓋の桟の上を通り、下のハードボードの下で締まる(パレットは通らない) |
| 　横バンド | (W×n + K) × 2 × 横本数 | mm | パレットの下まで回る |
| 縦バンドアングル | 縦本数 × 4 | 個 | 縦バンドが角を回る4か所のコーナー保護。単位質量は kg/個 |
| ハードボード | W×n × L × 2 ÷ 10⁶ | m² | 上下2枚 |
| VCフィルム | W × L × N ÷ 10⁶(面ごと) | m² | A面・B面それぞれに、その品名の単位質量 × 係数 |

合計:

| 名前 | 式 |
|---|---|
| 梱包資材重量(資材計) | 8資材の合計(チェックを外した資材は 0) |
| 風袋総重量 | パレット+蓋の重量 + 資材計 + 積合せ重量(積合せ有りのときだけ) |
| GW | 風袋総重量 + Aインプット重量(Aインプット重量が空・0 なら出さない) |
| 梱包数ごとの表 | 1梱包ぶん × 梱包数(1〜100)。最後の列は 資材計 + パレット+蓋(積合せは入れない) |

### 計算の例(1山積み)

板厚1 × 板幅1250 × 板丈2500 を 500枚、縦バンド2・横バンド4、梱包高さ700、山の高さ H = 500mm。
単位質量は試験用の値で、本物のマスタの値ではありません(係数はすべて 1)。

| 資材 | 基準量 | × 単位質量 | = 重量 |
|---|---|---|---|
| ダンプレート | (1250+2500)×2×500 ÷10⁶ = 3.75 m² | 0.250 | 0.94 kg |
| 外装紙 | (3750×2×500 + 1250×2500×2) ÷10⁶ = 10.0 m² | 0.0842 | 0.84 kg |
| ポリシート | ((1450+2700)×2×700 + 1450×2700) ÷10⁶ = 9.725 m² | 0.141 | 1.37 kg |
| 合紙 | 1250×2500×501 ÷10⁶ = 1565.6 m² | 0.023 | 36.01 kg |
| バンド | ((2500+500+10+40)×2×2 + (1250+700)×2×4) ÷10³ = 27.8 m | 0.077 | 2.14 kg |
| 縦バンドアングル | 2本 × 4 = 8 個 | 0.05 | 0.40 kg |
| ハードボード | 1250×2500×2 ÷10⁶ = 6.25 m² | 2.387 | 14.92 kg |

### 計算前の確かめ(通らなければ計算しない。全部まとめて出す)

| 確かめ | 断りの文 |
|---|---|
| 板厚・製品巾・製品丈が 0 / 空 | 「◯◯の入力が不正です。」 |
| 梱包締枚数が 0 / 空 | 「梱包総枚数を入力してください。」 |
| 横バンドが 1本以下 | 「横バンドの入力が不正です。」 |
| 梱包高さが空 / 山の高さ以下 | 「梱包高さを入力してください。」/「梱包高さの数値が不正です」 |
| 縦バンドが 0〜2 の整数でない | 「縦バンドは2本までです。」など |
| パレット+蓋の重量が空 | 「パレット重量を入力してください。」 |
| 縦バンド1本(EX2方向)で横バンドが4本でない(板幅 1220〜1300mm と包装仕様 7P0106 は除く) | 「EX2方向は横バンド4本」 |
| VCを使うのに品名が空 | 「VCを選択してください」 |
| 積合せ有りなのに重量が空 | 「積合せ重量を入れてください」 |
| 使う資材がマスタに無い(単位質量 0) | 「◯◯: 資材重量マスタに「…」がありません」 |
| 資材重量マスタが読めない | 「資材重量マスタを読めません(資材重量なし)」 |
| VCの品名がマスタに無い(**面ごと**に見る) | 「VCフィルム(B面)「…」: 登録されていないVCです」 |

### オーダーからの自動選択

| 決まるもの | 決まり方 |
|---|---|
| VC | 受注の VC_表 → A面、VC_裏 → B面。どちらも空なら使わない |
| 合紙 | 受注の「合紙」列が "1" なら使う。輸出形態が決めていればそちらが勝つ |
| バンド種別 | 既定は帯鉄シール無。取引先 ﾅﾒｶﾜｱﾙﾐ(ｶ は PET。輸出形態の表(取引先 + 納入先)で PET・合紙・縦1本。包装仕様 7P0106 は PET + 縦1本 |
| 縦バンドアングル | 縦バンドが1本以上なら使う |

自動で入ったものは画面で印が付き、人が変えられます。

### 出力

- 画面: 資材ごとの重量・梱包資材重量・風袋総重量・GW、梱包数ごとの表(1〜100)、梱包図(外形)、
  **内訳**(資材ごとに ①記号の式 ②数字を入れた式 ③基準量 ④基準量 × 単位質量 × 係数 = 重量、マスタの出どころ)
- 印刷: 梱包数を入れて、その行だけを A4 横1枚(資材計と風袋総重量。積合せ・Aインプット・GW は入れない)
- **記録**(v4.44.0): 計算・印刷の画面を開くたびに、**どの版で・どの取得元の・いつ時点の資材マスタで計算したか**を
  月ごとのファイルへ1行ずつ残す(版・資材マスタの取得元と場所・ファイルの更新日時・使った単位質量×係数・PC とライン・
  LotNo と GW)。形式は **CSV(既定。Excel で開ける)**・JSON Lines・両方 から設定・管理者の「出力」の面で選ぶ。この端末の `data/GW計算記録/` と、出力先を決めてあれば `<出力先>/<ライン>/GW計算記録/`(PC ごと)。
  画面の結果の下・紙の下の段にも同じ素性を出し、画面右上の「計算の記録」で一覧を見る

## 操作説明

1. 日報管理ツールの「GW計算」タブを開きます。
2. LotNo(7桁)を打って欄を離れます。寸法・材質・受注が入ります。引当が複数ならオーダーNoを選びます。
3. 梱包締枚数・縦バンド本数・横バンド本数・梱包高さ(パレット含)・パレット+蓋の重量を打ち、積み形態を選びます。
4. 使う資材・バンド種別・VC を確かめます(自動で入ったものには印。変えてもかまいません)。
5. 積合せがあれば「有り」にして重量を打ちます。GW が要るときは Aインプット重量を打ちます。
6. 「計算」を押します。断られたら、印の付いた欄を直してもう一度押します。
7. 数字を疑うときは「内訳」を開くと、どの式にどの数字を入れたかが出ます。
8. 紙が要るときは梱包数を入れて印刷します。
9. どの版・どの資材マスタ(いつ時点)で計算したかは、結果の下と紙の下に出ます。前の計算は画面右上の「計算の記録」で見ます。

## 思想(設計の考え方)

- **式は1か所。** 画面・内訳・印刷は同じ計算から作ります(「画面の説明と実際の計算が違う」を起こさない)。
- **軽いGWを出さない。** マスタに無い資材・VC、読めないマスタは 0 kg で続けずに断ります(輸出の書類に載る数のため)。
  VBA も型の不一致で止まっていました。
- **断りは全部まとめて出す。** VBA は1つずつ MsgBox で止めていたので、3か所違うと3回押し直していました。
- **意図が読めるように式に書く。** 係数が 1 でも省略しません(v4.38.0。VBA は VC だけ係数を省いていた)。
- **VBA と変えたところは理由を残す**(下の表)。

### VBA と違うところ

| 項目 | VBA | いま | 理由 |
|---|---|---|---|
| 梱包高さの確かめ | 板厚 × **全枚数** と比べる | 板厚 × **積み枚数**(山の高さ)と比べる | 2山・3山で正しい梱包高さを断っていた |
| ポリシート | 外装紙と同じ式(上下2面・余りなし) | 側面 + 天面、各寸法 +200mm | 現場の指定 |
| 縦バンドアングル | 板丈ぶんを2本の長さ(縦2本のときだけ) | 縦バンド1本につき4個(縦1本以上) | 蓋を使う梱包に合わせた(現場の指定) |
| 縦バンドの長さ | 板丈 + 山の高さ | 板丈 + 山の高さ + ハードボード 5mm × 2 + 蓋・桟 40mm | 縦バンドは蓋の桟の上を通る(現場の指定、v4.38.0) |
| VCフィルムの係数 | 掛けない | 掛ける | 係数 1 なので数は同じ。式に意図を残す(現場の指定、v4.38.0) |
| VCの未登録 | 合計が 0 のときだけ止める | 面ごとに止める | 片面だけ未登録だと、その面が 0 kg のまま通っていた(v4.37.3) |
| 積合せ重量が空 | 言うだけで計算していた | 断る | 積合せぶんが抜けたGWが出る |
| 断り | 1つずつ MsgBox | 全部まとめて | 押し直しを1回にする |

## モード説明

GW計算そのものには、権限で分かれる操作はありません。日報管理ツールを開ける人は誰でも計算・印刷できます。
マスタ(資材重量・VC重量)の置き場所は日報管理ツールの「設定」の参照設定で決めます(変えるには管理者のパスワード)。

## 用語

| 用語 | 意味 |
|---|---|
| GW | 総重量(Gross Weight)。風袋総重量 + 製品の重量(Aインプット重量) |
| 風袋総重量 | パレット+蓋 + 梱包資材 + 積合せ |
| 山 / 列 / 積み形態 | 板を横に何列並べて積むか。2山なら2列 |
| 積み枚数 | 1つの山の枚数。切り上げ(枚数 ÷ 列) |
| 山の高さ | 板厚 × 積み枚数 |
| 梱包高さ | パレットを含めた梱包全体の高さ |
| 単位質量 | マスタの1単位あたりの重さ(kg/m²・kg/m・kg/個) |
| 係数 | マスタの補正の値(いまは 1) |
| EX2方向 | 縦バンド1本の梱包。横バンドは4本が決まり |
| 積合せ | 同じ梱包に別の物を一緒に載せること。その重量を風袋に足す |
| Aインプット重量 | 製品(板)の重量 |
