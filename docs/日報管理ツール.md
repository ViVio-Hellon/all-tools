# 日報管理ツール(VER4.44.10)

> 入力の近道は [使い方/日報入力テクニック集.md](使い方/日報入力テクニック集.md)(場面ごとの早見表)。

梱包の実績(梱包実績日報表)を、直ごとに画面で打つツールです。打ったものはまずこのパソコンに残り、直の終わりに「共有へ保存」で、みんなが見る共有の日報データへ渡します。Excel VBA + Access で動いていた日報ツールを、Python(サーバ)+ ブラウザ画面に作り直したもので、日報複合ツールの「日報」のタブとして開きます。

- 置き場所: `tools/nippou`(版は `tools/nippou/config/app.json` の `version`)
- 操作説明書(画面写真つき): `portal/static/manual/nippou.html`(日報複合ツールの「説明書」ボタン)
- 細かい経緯: `tools/nippou/README.md`

## 仕様

### 必要なもの

Python 3.9 以上と Flask(ブラウザ版で動かすときは waitress も)。配布フォルダには同梱せず、各 PC に入っているものを使います。一覧は [日報複合ツール.md](日報複合ツール.md) の「必要なもの」にあります。Access(.accdb)との連携は追加パッケージ無し(cscript + VBScript、または ctypes)。

### 画面(左のタブ)

左の並びは作業の順です。番号はそのまま残ります。

| # | 画面 | 何をする画面か | だれが・いつ |
|---|---|---|---|
| 1 | 日報入力 | 12行の表に日報を打ち、このパソコンに保存する。直の終わりに共有へ保存する | 作業者・毎直 |
| 2 | 梱包資材重量計算 | 寸法から梱包資材の重量・風袋総重量・GW を出す。梱包図・印刷 | 要るとき |
| 3 | VC長さ計算 | VCフィルムの残り長さ・定尺ごとの枚数・早見表、コイル・平板の重量 | 要るとき |
| 4 | 記録を見る | 保存した直の紙を見る・刷る。ロットを探す。過去の直を呼び出して直す(管理者) | だれでも |
| 5 | 集計・グラフ | 重量・枚数・稼働率・停止をグラフで見る。集計CSVを出す | 班長など |
| 6 | 集計管理 | 日別・直別・ロット別の数字を表で見る。共有保存の履歴 | 班長など |
| 7 | 標準作業時間 | 同じ条件の作業時間の標準を見る・比べる。大きく超過した作業を探す | 班長など |
| 8 | 設定・管理者 | 共有へ保存・置き場所・マスタ・音・この端末のライン など | 班長・管理者 |

- 4・6・7 は、アクセス権限の表でこのパソコンの行に `mode:fullaccess` か `Administrator` があるときだけ出ます。無いパソコンは 1・2・3・5・8 だけです。表を読めない日は全部出ます。
- 「◯直 の実績」(直の実績確認)の画面が画面いっぱいに出るのは3つのときだけです: 日報入力の「共有へ保存」が通ったとき・残り5分の自動確定で共有へ自動で送れたとき・共有へ渡さないまま直が終わったとき(1度だけ)。直の終わりの15分前は画面を切り替えず、上に帯で知らせます。
- 日報入力の上(ページの案内の横)に、開いている直を共有へ保存したかが出ます: 「この直は共有へ保存済み(16:52 山田)」(緑)/「この直は自動で共有へ保存済み(14:55)」/「共有へ保存したあとに直した行があります。もう一度「共有へ保存」を押してください」(黄)/「この直はまだ共有へ保存していません」(灰の小さな字)。時刻と押した人は共有保存の履歴から、直したかは手元の未送信の印から決めます。
- 設定・管理者の中は面(タブ)に分かれています: 保存と出力 / マスタ / 音 / 取り込みと直し / 参照設定 / この端末と配布 / ログ。
- 「この端末と配布」の配布設定は、日報のフォルダの `配布設定\` に書き出します。日報複合ツールでは、大設定の「4ツールの分もまとめて書き出す」で、同じものが大設定の `配布設定\日報複合ツール.json` にも入ります(この1つのファイルだけでも届きます)。両方あるときは**作った時刻が新しいほう**を丸ごと使います(同じなら日報のフォルダのほう)。音声ファイルはまとめたファイルには入らず、日報のフォルダの `配布設定\音` のまま配ります。
- 標準作業時間の中の面: 標準(条件×班) / 同条件の作業 / 梱包力 / 考え方と計算 / 過去ぶんを入れる。

読み書きするDBは、手元も共有も参照マスタも sqlite3 です。共有と参照マスタの置き場所は、設定・管理者の「参照設定」で決めます(変えるには管理者パスワードが要ります)。

| 区分 | ファイル | 中身 | だれが書くか |
|---|---|---|---|
| この端末 | `%LOCALAPPDATA%\NippouTool\data\nippou_local.sqlite3` | 手元の日報。共有へ保存するまで、日報はここにしかありません | 自動保存・保存(確定) |
| この端末 | `…\NippouTool\runtime\user_config.json` | この端末の設定(ライン・参照パス・管理者パスワード) | 設定画面 |
| この端末 | `…\NippouTool\cache\source\` | 参照マスタの写し | ツール |
| この端末 | `…\NippouTool\logs\` / `work\` | ログ(「ログの出力パス」を決めていない・届かないときの `nippou\` フォルダ。前の版の `launcher.log` `guard.log` はもう書かない)/ CSV・印刷用HTMLの既定の出力先 | ツール |
| ログ(参照設定の「ログの出力パス」。既定はこの端末の `logs`) | `<ログの出力パス>\nippou\nippou_動作記録_<PC名>.log`(動いた記録)、`nippou\nippou_出来事_<年-月-日>_<PC名>.jsonl`(エラー・操作の記録。設定・管理者の「ログ」の面で探す)、`nippou\nippou_なぜなぜ_<PC名>.jsonl`、`nippou\nippou_起動_<PC名>.log`・`nippou\nippou_起動監視_<PC名>.log`(起動の記録。v4.44.5)、`nippou\書き出し\nippou_エラー一覧_<日時>.csv` | 共有のフォルダにすると全端末のエラーが1つの一覧に並ぶ。ツールの名前のフォルダ・名前の頭でほかのツールのログと分かれる(v4.44.4)。前の版が直下に書いた `出来事_….jsonl` `なぜなぜ_….jsonl` も読み、`nippou.log` はそのまま残す | ツール |
| 共有 | `日報データ.sqlite3` | みんなが見る日報。表は `T_日報ヘッダー_<ライン>` `T_日報明細_<ライン>`、集計の表 `T_日報集計_<ライン>` など | 「共有へ保存」だけ |
| 共有 | `標準作業時間.sqlite3`(日報データと同じフォルダ) | 全ライン・全端末の作業実績と標準(`T_作業実績` `T_標準作業時間`) | 共有へ保存で送れた直のぶん |
| 共有 | `LocalBackup\<ライン名>\日報入力データ.sqlite3` | 日報の控え(既定は日報データと同じフォルダ)。管理者が別のPCから直すのに使う | 手元へ保存したとき・共有へ送れたとき |
| 共有 | `自動集計\`(月別の書き出し先の既定) | 月替わりの書き出し | 共有へ保存のあと |
| 参照マスタ | `SIKALOT` `SIKAHIKI` `SIKAODR`(.sqlite3) | ロット → 寸法・材質・用途コード / 引当 / 受注(ＶＣ・合紙・単重・包装仕様NO)。置き場所は第1パス・第2パスの2つ。第2パスはファイル名も決められます | 読むだけ(手元へ写してから) |
| 参照マスタ | `LS4LOT.sqlite3` | コイルの割り数(機側・NS1 だけ)。第1パスは仕掛ロット・引当・受注と別の置き場所にでき、第1パス・第2パスともファイル名も決められます。名前が LS4LOT でなければ、BOX実績_作業開始_日付 が今の年月の行の BOX設計_縦割数・横割数を読みます | 読むだけ(手元へ写してから) |

仕掛のファイルの列と使い道は [仕掛ファイルとカラム.md](仕掛ファイルとカラム.md) にまとめてあります。
| 参照マスタ | `梱包資材マスタ.sqlite3` | 資材重量・VC重量・班員名簿・包装仕様の注意・アクセス権限 | 読むだけ(マスタ管理で直せる表もある) |
| 参照マスタ | `伝送用ファイル.sqlite3` | 停止理由(3分類)・直の境界時刻(時間用)・名簿 | 読むだけ(マスタ管理で直せる表もある) |
| 参照マスタ | `ライン毎目標.csv` / `停止内訳.csv` | 45度線の目標枚数 / 停止理由の一覧(あれば伝送用ファイルより先に読む) | メモ帳で直せる |
| 参照マスタ | `VC計算マスタ.sqlite3` | VC長さ計算の品種・定尺・早見表。無ければ初めて使うときに作ります | VC長さ計算 |

- 共有の参照マスタは直接開かず、手元へ写してから写しを読みます(開くとロックを取り、上流の置き換えを邪魔するため)。
- 書き先のファイル名を `日報データ.accdb` にしたときだけ Access へ書きます。既定の名前のままなら `.accdb` は拾いません。VBA の `日報データ.accdb` の中身は、設定の「日報データ.accdb から写す」で共有へ写せます(管理者)。
- ファイルの一覧と、実際のパス・あるか・消したらどうなるかは、設定・管理者 →「この端末と配布」→「ファイルの置き場所」に出ます。

### 保存の流れ

| 段 | 引き金 | 書く先 | 止めるとき |
|---|---|---|---|
| 打つ(自動保存) | 欄から離れるたび | `nippou_local.sqlite3` | 前回から60秒以内 / 他の直を開いている / 直の時間が過ぎた / 打てないタブ。間違いがあっても書きます |
| 保存(確定) | ボタン(途中で何度押してもよい) | `nippou_local.sqlite3` + 集計CSV | 下の表の「止める」が1件でもあるとき |
| 共有へ保存 | ボタン(直の終わりに1回) | 共有の `日報データ.sqlite3` | 下の7項目のどれかが通らないとき |

- 自動保存は打ちかけを残すためのものなので、間違いがあっても止めません。
- 「この直をチェック」は何も保存しません。直の途中でも押せる下見で、7項目を並べるだけです。
- 共有へ保存のボタンは2つあります。「共有へ保存」はいまの直だけ、「過去分を共有へ送る」は、いまの直ではない未送信の直をぜんぶ古い順に送ります(直すところがある直だけ送らずに残します)。
- 直の残り5分になると自動で「確定」(チェックと集計)が走り、直すところが無ければ、その直を共有へも送ります。

止める確かめ(7項目 + 休憩の時刻)

| 確かめ | 保存(確定) | 共有へ保存 | この直をチェック | 「設備移動のため保存」で通せるか |
|---|:--:|:--:|:--:|:--:|
| 梱包数(個装枚数 × 包数)が検入枚数より多い | 止める | 止める | 並べる | 通せない |
| 停止の記号が停止内訳(マスタ)に無い | 止める | 止める | 並べる | 通せない |
| 開始と終了が同じ | 止める | 止める | 並べる | 通せない |
| 1行の作業時間が直の規定時間より長い | 止める | 止める | 並べる | 通せない |
| 停止が作業時間を超える(作業時間がマイナス) | 止める | 止める | 並べる | 通せない |
| 最終時間まで入っていない(最後の行が直の終わりで終わっていない) | 通す | 止める | 並べる | 通せる |
| 休憩(記号 0 休憩食事)が合わせて60分に足りない | 通す | 止める | 並べる | 通せる |
| 休憩の時刻がありえない(v4.37.1) | 止める | 止める | 並べる | 通せない |

- 最終時間と休憩の2つは、直が終わらないと必ず「足りない」ので、保存(確定)では止めません。画面には「直の終わりまでに」の印つきで出ます。
- 確かめは、画面の入力ではなく、DBに入っている全ページを読み直して(ページをまたいで足して)から行います。
- 休憩の時刻で見るもの: 読めない時刻(25:00 など)/ 休憩の記号が無いのに時刻だけ / 時刻の長さと休憩の分が違う / 直の時間の外 / その行の作業時間の外 / ほかの行(ほかのページも)の休憩と重なる / 休憩とほかの停止の分を足すとその行に入りきらない。空のままなら止めません。
- 全停の直では休憩60分を求めません。
- 日勤は、最後の行が定時(17:00)のほか、残業の終わり(18:00 / 19:00)でも通します。

### 出力(CSV・印刷)

| 出力 | いつ | どこへ |
|---|---|---|
| 集計CSV(`集計_` 直ごとの合計 / `集計明細_` その日の明細 / `停止内訳_` 記号ごとの停止とどのページのどの行か) | 保存(確定)のあと自動・集計・グラフの「この期間の集計CSVを出力」 | `<出力先>\<ライン>\集計\<yyyy.mm>\<dd>\` |
| `CSVの読み方.txt` / `計算内容.csv` | 年月のフォルダに無いときだけ置く | `<出力先>\<ライン>\集計\<yyyy.mm>\` |
| 集計CSVの2つ目 | 共有へ保存のとき(送り終わった中身だけ) | 2つ目の出力先(空なら出さない) |
| 印刷用HTML(紙) | **共有へ保存**のとき(送った直の全ページ)・日報入力の**「印刷」**を押したとき(その直の全ページ)・「当直をDBから復旧」(管理者)。記録を見るの「紙を見る」は見るだけで残さない | `<出力先>\<ライン>\印刷\<yyyy.mm>\<dd>\印刷_<報告日>_<ライン>_<直>_<ページ>.html`(同じページは上書き) |
| 月替わりの書き出し(集計・停止集計・明細の3本) | 共有へ保存のあと(その月に未送信の直があれば見送る)・設定から手で | `<月別の書き出し先>\<ライン>\<yyyy.mm>\` |
| 標準作業時間 / 同条件作業のCSV | 標準作業時間の画面で押したとき | 標準作業時間の出力先(空なら集計CSVと同じ) |
| 共有保存の履歴のCSV / ロットを探すのCSV | 押したとき | 集計CSVと同じ出力先 / 集計管理と同じ出力先 |

- 出力先は設定画面で決めます(既定はこの端末の `work`)。共有のフォルダを指せば、ほかの人もそのまま開けます。
- 停止内訳CSVには「休憩の時刻」の列があり、休憩(記号 0)の1件ずつの行にだけ入ります。休憩の時刻は共有の日報データへは送りません(紙にも Access にも欄が無いため)。
- 紙は A4横1枚です。紙は刷らなくても日報は残ります。紙に出るのは保存してあるぶんだけです。作業停止④⑤は紙に無い欄で、使ったページだけ③の右に足して刷ります。

### 直と時刻の決まり

直の境界時刻は伝送用ファイルの「時間用」から読みます。読めないときは控えの時刻で動き、そのことを画面に出します。読むのは起動のとき・「時間マスタを取り込む」・マスタ管理で時間用を直したとき(直したPCはその場で効く)と、**マスタのファイルが変わったとき**です。ほかのPCで直しても、画面を開いていれば1分以内に効きます(30秒に1回までファイルの更新時刻を見て、変わっていれば読み直す)。

| 直 | 時刻(控えの値) | 前の直 |
|---|---|---|
| 1直 | 07:00 - 15:00 | 前の日の3直 |
| 2直 | 15:00 - 22:50 | 1直 |
| 3直 | 22:50 - 07:00(翌朝) | 2直 |
| 日勤 | 07:00 - 17:00(残業は19:00まで打てる) | 前の日の3直 |

- 日報の鍵は「報告日・ライン・直・ページ」です。1ページは12行です。
- 3直は始めた日の報告日です。0時を過ぎてから(00:00〜終了)打っても、前の日(始めた日)の3直に入ります。
- 入力先の直は、作業者を選んだ時点の時計で決まり、以後その直に固定されます。直の途中で境の時刻をまたいでも、書き先は変わりません。
- 直の終わりの時刻ちょうどで、入力画面は「見るだけ」になります(猶予は既定 0 分)。終わった直を直すのは「記録を見る」の呼び出す(管理者モード)です。
- 直の終わりの15分前に催促します。画面は切り替えず、上に帯「あと15分で直の終わりです。打ち終えたら「共有へ保存」を押してください」を出します(閉じられる。まだ共有へ保存していない直だけ。催促の音は今までどおり)。5分前に自動で確定し、直すところが無ければ共有へも送ります。送れたら「◯直 の実績」を画面いっぱいに出し、送れなかったら赤い帯「自動では共有へ送れませんでした。直すところがあります」を出して入力画面に留めます。紙は自動では出しません。
- 日勤のラインは時刻によらず日勤です(README では 丸徳・トット・バランサー)。日勤は日をまたぎません。
- 時間の上限(1行が直の規定時間より長いか)は直の長さで見ます。管理者モード中は全直の最大で見ます。

## 操作説明

### 毎日の流れ(直ひと回り)

画面の上の「直の進み具合」の帯(①作業者 → ②日報を入力 → ③保存 → ④確かめる → ⑤共有へ保存)も同じ順に並んでいます。

1. 日報複合ツールの大きなタブの「日報」を押します。「日報入力」が出るまで待ちます。
2. 上の帯で、ラインがこのパソコンのライン(例: L-1)になっているか見ます。「未設定」なら打てません。班長・管理者に知らせます。
3. 作業者を選びます。
   1. 「作業者を選ぶ」を押すと名簿の窓が開きます。
   2. 班の名前(A班 など)を押すとその班の全員に、名前を押すと1人ずつチェックが付きます。
   3. 「担当者欄へ反映」を押します。ここで直が決まり、表が打てるようになります。
   4. 昼稼働があるときは「昼稼働(有)」にチェックを付けます。
   5. 赤い「前の直」の帯が出たら、「過去分を共有へ送る」を押します。前の直に直すところが残っていて押せないときは「直せないまま引き継ぐ」を押し、班長に知らせます。
4. 行を打ちます(上の行から、1ロット1行)。
   1. LOTNO を7桁で打ちます。材・調質・製品寸法・検入枚数・合紙・ＶＣ種別・単重が自動で入ります(違っていたら打ち直せます)。引当が2つ以上あるときは「引当を選ぶ」の窓で選びます。前の直で同じロットを作業していると「1直で15枚作業しています。検入数を変えますか?(20枚 → 5枚)」と訊きます(はい で検入枚数が残りの枚数に。前の直から続くかぎり遡って数えます)。
   2. 梱包作業時間の開始・終了を「時」「分」2桁ずつ打ちます(例: 07 00)。終了を打つと次の行の開始に同じ時刻が入ります。時か分をダブルクリックすると、いまの時刻が入ります。
   3. 作業人数・個装単位 枚数・梱包単位 包数を打ちます(包数は空なら1)。実績合計の枚数・重量は自動で出ます。
   4. 「◯行目の重量を ◯◯ に変更しますか？」はふつう OK。量った重量を残したいときだけキャンセルします。
   5. etc は表の上のボタン(ｽﾄｱ・耳付・外注・EX・反転・ｽﾎﾟｯﾄ)で付けます。
   6. 行を空にするときは行番号の横の ✕ →「空にする」。
   7. 12行を使い切ったら「次ページ発行」。2ページ目の1行目の開始には、前のページの最後の終了が入ります。前のページは表の下の「ページ」の欄で選ぶと直せます。
5. 停止・その他理由・休憩の時刻を打ちます。
   1. 作業停止①〜⑤は「記号」を一覧から選び、「時間(分)」を打ちます。停止は5分以上のときに書きます。見出しの ①〜⑤ で出す組を替えます。
   2. 記号で「ヨ その他(理由を記載)」を選ぶと「理由を書く」の窓が出ます。理由を打って「理由欄へ入れる」。
   3. 記号で「0 休憩食事」を選ぶと「休憩の時刻」の窓が出ます。**先に①休憩の分**(例: 60)、**次に②何時から何時まで**(`11:30〜12:30`、`1130-1230` でも可)を打ち、「休憩の分と時刻を入れる」。分は停止の欄に入ります。分と時刻の長さが合わなければ窓がもう一度出ます(表の分だけあとで打ち直して合わなくなったときも)。1行に2つあるときは `10:00〜10:10、12:00〜12:50` と「、」で並べます。「時間を割り振る」が入れた休憩には、決まった休憩の時刻(1直なら 12:00〜13:00)が入ります。
   4. 休憩は直の中で合わせて60分要ります。
   5. 直のあいだ設備がずっと止まっていたときは「全停入力」(直に1回だけ)。
6. 保存(確定)を押します。
   1. 打っている途中で何度押してもかまいません。「保存しました」と出れば済みです。
   2. 断られたら、表の下の一覧に出た「◯ページ ◯行目」と欄を直して、もう一度押します。
   3. ここまでの保存はこのパソコンの中だけです。
7. 直の終わり(15分前ごろに、画面の上に帯「あと15分で直の終わりです…」が出ます。画面は切り替わりません)。
   1. 直の最後(1直なら 15:00)まで行を打ちます。休憩が合わせて60分あるかも見ます。
   2. 「保存(確定)」を押します。
   3. 「この直をチェック」を押し、「直すところはありません」と出るか見ます。出たらその行を直して 2 からやり直します。
   4. 「共有へ保存」を押します。送れると、画面いっぱいに「◯直 の実績」(この直の表と今月の推移のグラフ)が出ます。これが共有へ保存できた合図です(VBA の保存のあとのグラフと同じ)。「確認しました」で日報入力へ戻ると、上に「この直は共有へ保存済み(時刻 作業者)」が出たままになります。進み具合の帯は5つ全部に ✓、ページの札は「共有済」です。送れなかった・断られた・「過去分を共有へ送る」のときは、実績の画面は出ません。
   - 共有へ保存したあとに行を直して保存すると、印が「共有へ保存したあとに直した行があります。もう一度「共有へ保存」を押してください」に変わります。もう一度押せば戻ります。
   5. 設備移動などで最後まで打てないときは、断られたあとに出る欄へ「設備移動のため保存」と打って「このまま共有へ保存」を押します(最終時間・休憩の不足だけ通せます。通せるのはいまの直だけです)。
   6. 紙が要るときだけ「印刷」を押します。別の窓に紙が開き、「印刷する」(Ctrl+P)で刷ります。押したときに、その直の紙(印刷用HTML)が出力先にも残ります(共有へ保存のときにも残ります)。
8. 終わるときは、進み具合の帯の ⑤ に ✓ があるか見てから、右上の「終了」(または日報の画面の「■ 終了」)を押します。共有へ保存していない直は、閉じても手元に残りますが、みんなからは見えません。

### 記録を見る

1. 「保存した直」の一覧から直を選びます。共有へ未送信の直は、古くても上に出ます。直すところがある直は赤く出ます。
2. 「紙を見る」でその直の紙を別の窓に開きます(だれでも押せます。読むだけ)。
3. 一覧に無い古い直は、「日付を指定して見る」で報告日・ライン・直を選び、「中身を見る」「この直ぜんぶの紙」を押します。
4. ロット№から探すときは「ロットを探す」で期間とロット№(頭の数桁だけでも、全角でも可)を入れて「探す」。探す先は共有の日報データと、この端末のまだ送っていない行です。ラインはだれでも選べます(見るだけ)。
5. 過去の直を直すときは(管理者モード)「呼び出す」→ 日報入力で直して「保存(確定)」→「最新のページに戻る」→「共有へ保存」。呼び出しているあいだは、いまの直に打てません。

### 集計・グラフ / 集計管理

1. 開始日・終了日と見せ方(「その日」か「期間」)を選び、「表示」を押します。目標線(45度線)・ネオン表示のチェックもここです。
2. 本日の合計重量・枚数・稼働率・停止時間と、グラフが出ます。「大きく見る」で1つを大きくします。
3. 「この期間の集計CSVを出力」で期間ぶんの集計CSVを出します(出し先は画面に出ます)。
4. 集計管理では、同じ数字を表(日別・直別・ロット別など)で見ます。CSVが要るときは「4本ともCSVに出す」。いちばん下に「共有保存の履歴」(各直で押した時刻と人)があります。
5. Administrator のパソコンでは、「表示」の隣のラインの欄でほかのラインを選べます(1ラインずつ。混ぜません)。

### 標準作業時間(大きく超過)

1. 「標準(条件×班)」の面で、ライン・班・用途コード・包装仕様NO・サイズを入れて「表示」を押します。
2. 梱包数と人数を入れると、行ごとに見積り(分)の列が付きます。
3. 「大きく超過(件)」が1件以上の条件の行は色が付きます。行の「抽出」で「同条件の作業」の面へ移ります。
4. 「大きく超過した作業だけ」に印を付けると、その作業(作業者・LOT・停止の分)を1件ずつ見られます。
5. 大きく超過 = 作業時間(停止を全部引いた分)が標準の1.5倍以上で、しかも10分以上長い作業です。標準が「仮」(作業3件未満)の条件では出しません。休憩の時刻がありえない作業は数えません。
6. 標準に溜まるのは「共有へ保存」で送れた直のぶんです。過去ぶんは「過去ぶんを入れる」の面から入れます。

### 設定・管理者

1. ふだん作業者が触るのは「保存と出力」の「共有へ保存(いまの直)」と「過去分を共有へ送る」くらいです(日報入力の2つのボタンと同じ働き)。
2. 管理者モードにするときは、面の上の鍵に管理者パスワードを打ちます。上の帯に印が出ます。終わるときは印の ✕ を押します。
3. この端末のラインは、ふつうはアクセス権限の表で自動で決まります。決まらないときは「この端末と配布」→「この端末のライン」で決めます(管理者モード)。表を書き直したら「読み直す」。
4. 置き場所(パス)を変えるときは、どれも管理者パスワードが要ります。
5. 「取り込みと直し」(過去の日報の取り込み・当直をDBから復旧・集計の作り直し・日報データ.accdb から写す など)は全部管理者モードが要ります。
6. 管理者パスワードを紙に書いてパソコンに貼らないでください。ほかのラインのパソコンのラインを変えないでください。

## 思想(設計の考え方)

README にくり返し出てくる考え方です。

| 考え方 | 中身 | README の言い方 |
|---|---|---|
| 判断はサーバ・画面は写すだけ | 業務の判断はすべて Python。JavaScript は受け取った結果を画面に出すだけ。保存を断るのもサーバ | 「業務判断はすべて Python。JS が持つのは『ビューモデル → DOM』だけ」「画面は写すだけ」 |
| 同じ事実を2か所に持たない | 規則や数え方は1か所に置き、画面・ボタンはそれを読む | 「同じ事実を2か所に持たない。持つと必ずどちらかが古くなる」 |
| 打っている途中で止めない、止めるのは保存(確定) | 打つ自由は残し、間違った行には消えない印を付ける。関門は保存(確定)と共有へ保存に置く | 「打つのは止めない。保存(確定)で止める」 |
| 止めるときは、どこを・どう直すかまで出す | 見つけた間違いは1つ目で止めず全部返す。1件ごとにページ・行・欄と直し方、そのページを開くボタン | 「見つけたものは全部返す。1つ目で止めない」「どこと、どう直すかまで持つ」 |
| 黙って捨てない | 読めない行(目標CSV・停止内訳CSV など)は行番号つきで画面に出す。確かめられなかったときは「直すところはありません」と言わない | 「読めない行は、黙って捨てない」 |
| 共有に書けないときは手元に預かって後で送る | 日報は共有へ保存するまで手元に残り、「共有へ未送信 ◯直ぶん」と出し続ける。共有保存の履歴・標準作業時間・控え(LocalBackup)も、届かなければ手元の待ちに残し、次に送れたときに写す | 「共有が開けない・まだ無いときは手元に残り、次の『共有へ保存』でまとめて写します」 |
| 記録が書けないことで止めない | ログの置き場所に届かなければ手元の logs へ書く | 「記録が書けないことで日報を止めません」 |
| 逃げ道は「打つ」 | 「設備移動のため保存」はボタンではなく文を打たせる。通せるのは最終時間・休憩だけ | 「ボタン1つにしないのは、押し流されるからです」 |
| VBA との違いは理由を書いて残す | VBA の手続き名と対応を書き、変えたところは「動きが変わります」「VBA と変えたところ」として理由を残す | 例: 保存と印刷を分けた、日勤の残業を通す、月初削除は移植しない |
| 閉じるからには出口を置く | 見るだけになった画面には、理由と次に押すボタン(次の直を始める・最新のページに戻る)を出す | 「閉じるからには、出口を置く」 |

## モード説明

アクセス権限の表は梱包資材マスタの「アクセス権限」です。ログインID と PC名 が当てはまる行の権限を全部使います(空欄は問わない。「有効」が0の行は読まない)。日報が読む値は `Administrator`・`mode:fullaccess`・ライン名の3つで、ほかの値(`mode:field` など)は読みません。

| 名前 | なれる人・なり方 | できること | できないこと |
|---|---|---|---|
| 作業者(ふつうの端末) | 日報を開いて「作業者を選ぶ」 | いまの直を打つ・保存(確定)・共有へ保存・過去分を共有へ送る・直せないまま引き継ぐ。同じ直の中で前のページに戻って直す。紙を見る・ロットを探す(全ラインを見るだけ)。いまの直に「設備移動のため保存」 | 終わった直・ほかの直を呼び出して直す。パスを変える。取り込みと直し |
| 班長 | ツールに「班長」という設定はありません。説明書では、集計・設定を見る人、管理者パスワードを知っている人として出てきます | 管理者パスワードを知っていれば、下の管理者モードと同じ | ― |
| 管理者モード | 設定・管理者の鍵に管理者パスワードを打つ。印の ✕ で終わる。直の変わり目で自動で外れる | 過去の直・ほかの直を呼び出して直す(控えからほかのラインも)。前の直の「設備移動のため保存」を通す。この端末のラインを変える。パスを変える。取り込みと直し。マスタを直す。「時間を割り振る」をオンにする | 集計管理・集計・グラフでほかのラインを選ぶ(Administrator だけ) |
| Administrator | アクセス権限の表で、このパソコンの行の権限に `Administrator` | どのラインの日報も「記録を見る」で見て直せる(パスワード不要)。集計管理・集計・グラフでラインを選べる(1ラインずつ)。左のタブ1〜8を全部出す | この端末のラインを変える(管理者モードが要る) |
| mode:fullaccess | アクセス権限の表で `mode:fullaccess` | 左のタブ1〜8を全部出す(4 記録を見る・6 集計管理・7 標準作業時間) | それ以外は変わらない |
| 端末のライン固定 | 権限にライン名を1つだけ書く(`L-1` `LVC` `HVC` `トット` `バランサー` `AIM` `機側` `NS1` `中板`。中板は `中板3` のようにラインNOを続ける) | そのラインの日報として打つ。ラインは表の値が変わったときだけ当て直す | 表の書き方が違う名前(L1・LS・l-1 など)は読まない。ラインが2つ当たると決めない |
| 行が無い端末 | アクセス権限の表に当てはまる行が無い | ラインは設定・管理者で決める。左のタブは 1・2・3・5・8 だけ(表を読めないときは全部) | ラインが決まるまで日報を打つ |
| 見るだけ | 直の時間が過ぎた / 2枚目に開いたタブ / 過去データを開いていて管理者モードでない | 見る。出口のボタン(次の直を始める・このタブで入力する・最新のページに戻る) | 打つ・保存する(サーバが断ります) |

- 大きなタブ(日報・看板 など)を出すかどうかは、この表ではなく共有の DB の「タブ表示権限」で決めます。

## GW計算

梱包資材重量計算(左のタブ2)で、LotNo と梱包の形(板厚・板幅・板丈・梱包締枚数・バンド本数・梱包高さ・パレット+蓋の重量)を打つと、資材ごとの重量・梱包資材重量・風袋総重量・GW が出ます。GW を出すときは Aインプット重量も打ちます。v4.37.3 で8つの資材の式を手計算と突き合わせ、VCフィルムの片面だけがマスタに無いときに軽い GW が出ていたのを直しました(面ごとに断ります)。v4.38.0 で、縦バンドの長さにハードボード上下(5mm × 2)と蓋・桟(40mm)を足し、VCフィルムにも係数を掛けるようにしました。

計算式と点検の結果は [GW計算.md](GW計算.md) にあります。

## 用語

| ページ | 12行の紙1枚。使い切ったら「次ページ発行」で足します |
| 保存(確定) | このパソコンへの保存。集計CSVも作り直します。共有へはまだ渡りません |
| 共有へ保存 | いまの直を、みんなが見る共有の日報データへ渡すこと。直の終わりに1回 |
| 過去分を共有へ送る | いまの直ではない未送信の直をぜんぶ、古い順に1回で送るボタン。直すところのある直だけ残します |
| 共有へ未送信 ◯直ぶん | まだ共有へ渡していない直の数。左の並びに赤で出ます |
| 共有済 / 未送信 | ページの札。共有へ渡したか |
| この直をチェック | 7項目を並べて見るボタン。何も保存しません |
| 7項目 | 共有へ保存の前に見る確かめ(梱包数・停止記号・開始と終了・1行の長さ・作業時間のマイナス・最終時間・休憩60分) |
| 直すところ | 確かめに引っかかったもの。ページ・行・直し方つきで出ます |
| 設備移動のため保存 | 最後まで打てない直を、最終時間・休憩の不足だけ通して共有へ保存するために打つ文 |
| 直せないまま引き継ぐ | 前の直が送れないまま次の直を始めるボタン。班長に知らせます |
| 全停 / 全停入力 | 直のあいだ設備がずっと止まっていたときの入力。直に1回だけ。全停の直は休憩60分を求めません |
| 自動確定 | 直の残り5分で走るチェックと集計。綺麗ならいまの直を共有へも送ります。送ったあとは手で押した「共有へ保存」と同じく、印刷用HTMLを残し、月替わりも書き出します(紙は刷りません)。送れたら「◯直 の実績」を画面いっぱいに出し、日報入力の印は「この直は自動で共有へ保存済み(時刻)」。送れなければ赤い帯で知らせます |
| 見るだけ | 打つことも保存することもできない状態の画面 |
| 呼び出す | 過去の直を日報入力に開いて直すこと(管理者モード) |
| 停止内訳 / 停止の記号 | 停止理由の一覧。記号は数字(管理ロス)・カタカナ(段取り・突発)・英字(ハンドリング) |
| 休憩の時刻 | 休憩(記号 0)を何時から何時まで取ったか。標準時間の「大きく超過」を正しく出すために打ちます |
| 標準時間(標準作業時間) | 同じ条件(ライン・班・用途コード・包装仕様NO・サイズ)の作業の、1梱包あたり人・分の中央値 |
| 仮 | 作業が3件未満で、標準がまだ決まっていない条件の印 |
| 大きく超過 | 標準の1.5倍以上で、しかも10分以上長くかかった作業 |
| 梱包力 | 標準を100とした梱包の速さ |
| 45度線 | ライン毎目標の累積の目標線(グラフの赤い点線) |

| 参照マスタ | 読むだけのマスタ(SIKALOT・伝送用ファイル など)。手元へ写してから読みます |
| SIKALOT / SIKAHIKI / SIKAODR | 仕掛のロット / 引当 / 受注のファイル |

| 時間を割り振る | 時刻を打たずに、直の始めから終わりまでを打った行へ割り振るボタン(オンにした端末だけ)。停止の分は先にその行へ渡し、残りは梱包数(枚数 × 包数)の比で分ける(梱包数が無ければ等しく)。休憩(1直 12:00〜13:00・2直 18:00〜19:00・3直 02:00〜03:00)にかかる行は60分のばして(行はつながったまま)、その行へ休憩「0」60分と時刻を入れる(昼稼働「有」の直はのばさない)。ほかの行の休憩「0」はそこへ移して1つにまとめる。決まった休憩と重ならない時刻を書いた休憩(直の中)は別の休憩として残す。またぐ行の停止①〜⑤が埋まっていれば割り振らない。EX のロットの行は長め・ロット№が変わる行の1梱包目は段取りのぶん長め・前のロットと VC が違えば VC交換のぶんも。段取り(板)の停止がある行は段取りのぶんを、VC交換(板)の停止がある行は VC交換のぶんを足さない(名前に「段取」があり「変更」が無い停止・「VC」と「交換」がある停止。段取り変更では変えない)(倍率は設定・管理者で変えられる。既定 EX 1.2倍・段取り 1.5倍・VC交換 1.5倍。v4.42.0) |
| LOTで時間を割り振る | 選んでいる行のロットの行だけ(選んでいなければ直の最後のロット)を割り振るボタン。始まりは1ロット目なら直の開始、2ロット目以降は前のロットの最後の行の終了。終わりはそのロットの最後の行に終了が入っていればその時刻、無ければ次のロットの開始、最後のロットなら押した時刻(ダブルクリックと同じく5分に寄せる)。前のロットもやり直せる(「時間を割り振る」をオンにした端末だけ)。ほかのロットの行は触らない。停止・休憩・EX・段取り・VC交換は「時間を割り振る」と同じ。区切りは時計の5分刻み。v4.43.0 |
