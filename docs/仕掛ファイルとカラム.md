# 仕掛ファイルとカラム(日報管理ツール VER4.40.1)

日報入力でロット番号を打ったとき、日報管理ツールが読む**仕掛のファイル**と、その中の**どの列を何に使うか**の決まりです。
読むのは表「**仕掛**」だけで、書き込みは一度もしません(上流のホスト系が作って置き直すファイルのため)。

- コード: `tools/nippou/nippou/access_bridge/gw_master.py`(読む)・`tools/nippou/nippou/logic/lot_fill.py`(日報の欄へ入れる)
- 置き場所の設定: `tools/nippou/nippou/config.py`(設定・管理者 →「参照設定」)
- 試験: `tools/nippou/tests/test_wip_paths_4400.py`・`test_wip_second_dir.py`・`test_coil_split.py`・`test_web_entry_lot.py`

## 1. 置き場所(仕掛パス)

| | 置き場所(参照設定の欄) | ファイル名 |
|---|---|---|
| **第1パス** 仕掛ロット・仕掛引当・仕掛受注 | 仕掛ロット・引当・受注の置き場所(第1パス)。空なら参照用マスタと同じフォルダ | `SIKALOT.sqlite3` / `SIKAHIKI.sqlite3` / `SIKAODR.sqlite3`(**固定**) |
| **第1パス** コイル割り数 | コイル割り数(LS4LOT)の置き場所(第1パス)。**空なら上と同じフォルダ** | コイル割り数のファイル名(第1パス)。**変えられる**。空なら `LS4LOT.sqlite3` |
| **第2パス** 4つとも | 仕掛の置き場所(第2パス)。空なら第2パスは見ない | **4つとも変えられる**(仕掛ロット・引当・受注・コイル割り数のファイル名(2つ目))。空なら第1パスと同じ名前 |

- **探す順は 第1パス → 第2パス。** 第1パスにファイルが無い・壊れている・中に「仕掛」の表が無い・そのロット(引当・受注)が
  無いときに、第2パスを見ます(ファイルごと・ロットごと)。
- コイル割り数だけは、最後に**梱包資材マスタのフォルダ**も見ます(v4.24.0 までの置き場所)。
- 同じ名前の `.sqlite3` / `.db` があればそちらを使います(`config._pick_source`)。

### 読むときは必ず手元へ写してから

第1パス・第2パスとも、**共有のファイルは直接開きません。** 手元(`%LOCALAPPDATA%\NippouTool\cache\source`)へ写して、
写したほうを開きます(大きさと更新時刻が同じなら写し直しません)。

| ファイルの形 | 写し方 |
|---|---|
| `.sqlite3` / `.db` | `source_db.local_copy`(写したあと中身が揃っているかを確かめる) |
| `.accdb` / `.mdb`(ファイル名に決めたとき) | `source_db.local_copy_file`(v4.40.0)。写したほうを Access の道(cscript + ACE・ODBC)で読む |

開いているあいだは上流がファイルを置き換えられない(Windows)ので、共有のファイルを開いたままにしないための決まりです。

## 2. 仕掛ロット(SIKALOT)

ﾛｯﾄ番号 で引きます(`gw_master.search_lot`)。先頭の1行を使います。

| 列 | 使い道 | 日報の欄 |
|---|---|---|
| `ﾛｯﾄ番号` | 引く鍵 | ― |
| `製造材質` / `製造調質` | 材質・調質 | 材質(ZAI) |
| `製造板厚` / `製造板幅` / `製造板丈` | 製品の寸法(Gコースでないとき) | 寸法(SIZ) |
| `設計_設備ｺｰｽ` | Gコース(GCT / GFS / GSS を含む)か。etc の印 | 寸法の出どころ・etc |
| `BOX最終実績_板厚` / `_板幅` / `_板丈` | Gコースのときの寸法(3つとも空・0 なら製造の寸法) | 寸法(SIZ) |
| `BOX設計_板厚` / `_板幅` / `_板丈` | 第1パスの SIKALOT に BOX最終実績が無いとき、**第2パスの SIKALOT** のこれを使う | 寸法(SIZ) |
| `BOX最終実績_枚本数`(空・0 なら `BOX実績_枚本数`) | 検入枚数(整数) | 検入枚数(KEN) |
| `梱包_合紙` | 合紙(受注の `合紙` が無いとき) | 合紙(AI) |
| `用途ｺｰﾄﾞ` / `用途名` | 紙の外の列 | others1 / others2 |
| `納入先名` | 紙の外の列 | others3 |
| `ｵｰﾀﾞｰ番号` `検査番号` `取引先名` `送り先名` `鋳造番号` | GW計算・画面の表示 | ― |

## 3. 仕掛引当(SIKAHIKI)

ﾛｯﾄ番号 で引き、**受注番号のある行だけ**を全部使います(`gw_master.search_allocations`)。2件以上なら画面で選びます。
受注番号のある行が無ければ「引当が無い」とみなして第2パスを見ます。

| 列 | 使い道 |
|---|---|
| `ﾛｯﾄ番号` | 引く鍵 |
| `受注番号` | 仕掛受注を引く鍵(ロットから受注を知る道はここだけ) |
| `引当番号` | 選ぶときの番号(8桁の文字のまま)・並べる順 |
| `引当数量` / `引当調整NO` | 選ぶときに並べる数量 |

## 4. 仕掛受注(SIKAODR)

引当で決まった 受注番号 で引きます(`gw_master.search_order`)。先頭の1行を使います。

| 列 | 使い道 | 日報の欄 |
|---|---|---|
| `受注番号` | 引く鍵 | ― |
| `VC_表` / `VC_裏` | VC | VC |
| `製品単重` | 単重 | 単重(UNI) |
| `合紙` | 合紙("1" なら有) | 合紙(AI) |
| `包装仕様NO` | 包装仕様の注意・紙の外の列 | others4・etc |
| `EX_輸出区分` | 輸出なら etc に「EX」 | etc |
| `取引先名称` `納入先名称` `送り先名称` | GW計算・画面の表示 | ― |

## 5. コイル割り数(LS4LOT など)── **ファイルの名前で見る列が変わる**(v4.40.1)

**機側・NS1 のときだけ**引きます(コイル形状)。ﾛｯﾄ番号 で引き、置き場所ごとに**そのファイルの名前**で次のどちらかにします
(`gw_master.search_coil_split`)。

| ファイルの名前 | 絞り込み | 縦割(others5) | 横割(others6) |
|---|---|---|---|
| **LS4LOT**(`LS4LOT.sqlite3` など。拡張子・大文字小文字は見ない) | ﾛｯﾄ番号 だけ。最後の行 | `当工程設計_縦割数` | `当工程設計_横割数` |
| **LS4LOT 以外**(`LS4LOT2.sqlite3`・`SIKALOT_コイル.sqlite3` など) | ﾛｯﾄ番号 と、**`BOX実績_作業開始_日付` が今の年月**の行だけ。複数なら作業開始がいちばん新しい行 | `BOX設計_縦割数`(= 当工程設計_縦割数) | `BOX設計_横割数`(= 当工程設計_横割数) |

- `BOX実績_作業開始_日付` は `2026-10-21 00:01:56` の形です。**年と月(`2026-10`)だけ**を、引いたときの年月と比べます
  (`2026/10/21` の形も読みます)。先月・去年の同じ月の行は拾いません。
- 今の年月の行が無いファイルは「無い」とみなして、次の置き場所(第2パス → 梱包資材マスタのフォルダ)を見ます。
- どこにも無ければ縦割・横割は空のまま。日報の入力は止めません。

## 6. 変えたとき

- ファイル名を変えても、**上の列名はそろえておいてください**(列が無いと、その欄が空になります)。
- 列の決まりを変えるときは、この文書・`gw_master.py`・試験(`test_wip_paths_4400.py`)を一緒に直します。
